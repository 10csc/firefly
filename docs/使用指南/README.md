## 这是什么

Firefly（萤火虫）是一个 **AI 角色扮演应用**。它不是真人，所有回复由你填写的 AI 服务（默认 DeepSeek）
在你自己的设备上生成。数据保存在本机，升级版本不会覆盖。

## 阅读约定

- **截图**：文中标注了截图位置；标了「（待补图）」的是**还没截**，不是文件丢了，请以文字说明为准。
- **措辞一致**：同一件事在全篇、以及在 App 界面里，用**同一句说法**；如果你在界面看到与本文不同的话，
  以界面为准并欢迎反馈。
- **不吓人**：绝大多数报错**不是你的设备或操作的问题**（多为 AI 服务临时波动）。
  不确定时先按排障表重试一次，仍不行再反馈。

## 一句话底线

- 你的**对话、记忆、手账、照片**都在你自己设备上，`升级版本不会覆盖`，卸载 App 才会清空（手机端）。
- 你的 **API Key 只存本机**，不会上传给 Firefly 的服务器。
- 平台账号只用于**逛广场 / 做卡 / 发布**；它和你的本机对话数据是分开的。

遇到任何问题，右下角（手机）/ 首页左上「✉ 反馈」（PC）都能找到反馈入口，
也可以先导出一份**诊断包**再一起发给我们（诊断包在本机生成，不经过服务器）。
