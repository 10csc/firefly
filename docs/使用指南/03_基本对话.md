# 03 · 基本对话

> 覆盖：发消息、切角色卡、发图 / 表情、语音、常见状态含义。遇到报错看
> [常见问题与排障对照表](05_常见问题与排障对照表.md)。

## 一、开始对话

1. 回到**首页**，点任意一张角色卡片（例如「剧情模式」），进入和这个角色的聊天页。
2. 在底部输入框里输入想说的话，点**「发送」**（或按回车）。
3. 稍等片刻，角色会回复。等待期间顶部会显示状态字（见第四节）。

> 首页上的**每一张卡片 = 一个「角色包」**，包含这个角色的人设 + **你和他之间的聊天数据**。
> 同一个角色可以有多个包（例如剧情线和剧本线各一个），**各自的对话互不串扰**。

## 二、切换角色卡

- **换角色**：在聊天页返回首页（或列表），点另一张卡片即可进入另一个角色。
- **编辑角色**：首页 →「角色卡管理」→ 点某张卡，可以改人设、用户设定、知识库、出厂记忆、表情包等，
  保存后**自动生效**。
- **记忆与手账**属于**聊天产生的私有数据**，在聊天页 ☰ 菜单 →「设定文件」里查看（见第五节）。

## 三、发图片和表情

- **发图片**：输入框右侧 **🖼** 按钮选图。图片会**压缩后上传**，**原图不出设备**。
- **发表情包**：输入框右侧 **😊** 按钮选表情，或直接在设置里管理表情包。
  「设置 / 菜单 → 表情包」可以添加、启用 / 停用、写含义描述——**描述越清楚，AI 选图越准**。

## 四、常见状态含义

聊天页顶部的状态字，是告诉你**现在进行到哪一步**，不是报错：

| 状态字 | 含义 |
|---|---|
| 「对方正在输入…」 | 正在生成回复，正常等待即可 |
| 「正在理解你的话…」等阶段字 | 分别对应：检索设定 → 分析意图 → 生成回复 → 挑表情包 |
| **「上游有点忙，正在努力回复…」** | AI 服务这一轮偏慢，**不是你的问题**，继续等或稍后重发 |
| 「这是上游接口的临时限制，不是你的卡或操作的问题：约 1 分钟后会自动重试」 | AI 服务临时限流，**不是你的操作问题**，约 1 分钟后会自动重试 |

**等太久没动静怎么办**：再发一条消息即可；若界面一直卡着，返回首页再进来。
具体归因与下一步请看[排障对照表](05_常见问题与排障对照表.md)。

## 五、常用操作（聊天页 ☰ 菜单）

| 想做的事 | 怎么做 |
|---|---|
| 引用某条消息 | **长按**该消息 →「引用」，输入框上方出现引用条，随消息发出 |
| 收藏某条消息 | 长按该消息 →「收藏」 |
| 撤回上一轮 | ☰ 菜单 →「撤回上一轮」 |
| 清除历史 | ☰ 菜单 →「清除历史」（**会一并清空记忆与手账**，谨慎） |
| 让角色休息 | ☰ 菜单 →「让角色休息」：把这段对话整理进**记忆**与**手账** |
| 看设定文件 | ☰ 菜单 →「设定文件」：用户记忆、历史对话存档、手账 |

**记忆怎么走**（简单版）：角色读的是**最近一段完整对话**；攒到约 100 轮时，App 会自动把
较早的部分搬进「历史对话存档」（供检索用），并在聊天页顶部提示。你也可以随时点「让角色休息」**立刻整理**。

## 六、语音（让角色「说」出来）

**怎么用**：在聊天页**长按某条消息 →「转语音」**。生成后，**语音条会贴在消息气泡下方**，
点一下播放 / 再点暂停。语气可在「首页 → 语音插件」里选（长按转语音时使用所选语气）。

**如实说明性能与限制**（避免误会）：

- 语音模型与**手机端同款**，首次使用需要**下载约 872MB** 的模型文件（请预留空间、接好网络）。
- 生成**单句通常要十几秒**；**刚启动或首次使用会更慢一些**（要先把模型装载进来）。
- 生成期间会提示「正在生成语音…」；**正在生成上一句时**请稍候，不要连续点。
- 偶尔可能遇到个别句子**听起来像说到一半**——这是已知的偶发现象，**再点一次重新生成**通常就好。
- 语音**原声版权归米哈游所有**，仅供个人二次创作使用。

想释放空间：**首页 → 语音插件 → 清除语音缓存**（只删已生成的音频，不影响模型与聊天记录）；
不再需要语音可**卸载语音插件**（会删掉约 872MB 的模型文件，已生成的语音不受影响）。

## 七、主动消息与自动修复

- **主动消息**：在「角色卡管理」→ 点某张卡 →「主动消息」里开关与调频率（**按角色独立**）。
- **自动修复**：小问题修好后，服务器会推一个补丁，App 空闲时**自动装上，不必重装**。
  在 **设置 →「数据」→「自动修复」** 里可开关、查看当前修复版本、手动检查，出问题还能「回退修复」。

## 八、公告与内置使用指南

首页上方「**公告 · 使用指南**」里有两个页签：

- **公告**：服务器下发的更新说明与临时提醒（有新内容时标题旁亮一个小圆点）。
- **使用指南**：App **内置**、**离线可看**的简明说明；即使拉不到公告，功能与指南都不受影响。

> 拉不到公告（离线 / 服务临时不可用）是**正常降级**，**不影响你聊天**。
