# 04 · 角色卡平台（广场 / 制卡 / 改编）

> 角色卡平台是**服务端的一个网站**，**登录后才能用**（登录见 [01 · 安装与登录](01_安装与登录.md)）。
> 它做的事：**浏览并下载别人做好的角色卡**、**自己做卡发布**、**从已有卡改编**。
> 平台账号与你的**本机对话数据是分开的**。

## 一、它长什么样

登录网站后主要有四处：

| 位置 | 用途 |
|---|---|
| **广场** | 浏览、搜索、筛选、查看详情、下载安装角色卡 |
| **制卡 / 我的卡** | 从零做一张卡，或管理自己的草稿与已发布卡 |
| **改编** | 以**已发布的卡**为模板，改出一张属于自己的新卡 |
| **治理台** | 仅管理员可见：下架、官方标记、处理举报 |

在 **App 内**也有入口：**角色包管理页 →「广场」**，可以浏览 → 下载 → 安装到本机使用。

## 二、浏览广场

- **需要登录**：未登录时看不到卡片内容；点「去登录」登录后即可浏览。
- **找卡**：支持**分类 / 标签筛选、关键词搜索、排序**，列表**默认折叠**，点标题行展开看简介。
- **看详情**：点开卡片查看完整简介、分类标签、作者与更新时间。
- **官方标识**：由**官方账号**发布的卡带一个 **「官方」徽标**；普通作者无法把自己标成官方。

> 数量多了以后，列表会**分页**。若某一页转圈较久，稍等或刷新一次即可。

## 三、安装到本机

**在哪装**：App 的**角色包管理页 →「广场」** → 选卡 → **下载 → 安装为包**。

- 安装成功后，这张卡会出现在你的**角色列表**里，**可以像内置卡一样开新对话**。
- 卡里带的**知识库**（设定资料）会进检索，**表情包**会进表情选择器。
- **不会**把**用户数据**（对话 / 记忆 / 手账）随卡发给你——卡只管人设与素材。
- **覆盖安装**（同 id 新版）会**先留一份备份**，再替换；**旧版多余的文件会被清掉**。
- **卸载**：从本机移除这张卡（可随时从广场**重新安装**）。卡专属的表情包也会一并清理。

### 配额上限（服务器模式下）

| 项目 | 上限 |
|---|---|
| 已安装的广场角色卡张数 | **最多 5 张**（可先卸载不再使用的） |
| 已安装卡的总占用 | **不超过 8MB** |
| 本地版 | **不限额**（本地运行不受此限） |

超过时界面会明确告诉你**当前已用多少、上限多少**，按提示**卸载 / 删减**后重试即可。

## 四、自己做卡（发布到广场）

**入口**：平台「制卡」，或 App 里某张角色卡的「**发布到广场 →**」。

**能做哪些**（自由度与 App 内的「角色卡管理」对齐）：

- 人设三件套 + 角色称呼 + 用户称呼；
- 简介、分类、标签、开场白、展示形态；
- **自由增删文本文件**（例如知识库），可写多份、也可分组；
- **头像**与**最多 8 张表情包**（表情包**建议填含义标签**——不填的话 AI 基本选不中）。

**图片规格（系统会按此裁剪 / 校验，超出会被拒）**：

| 用途 | 目标尺寸 | 体积上限 |
|---|---|---|
| 列表小图 | 长边 ≤320px | **≤12KB**（硬线） |
| 头像 | ≤256px | ≤30KB |
| 详情大图 | ≤1024px | ≤300KB |
| 每张表情包 | ≤160px | ≤20KB |

**其他上限**（超了会给明确中文提示）：

- 标签最多 **20** 个；
- 草稿最多 **50** 份（管理员不限）；
- 卡内文本文件最多 **500** 个；
- 单卡**文字总量 ≤8MB**；整卡体积 ≤**10MB**；
- 文本扩展名限 `.md` / `.txt` / `.json`。

## 五、发布前要过审核

- 提交后由 **AI 审核**。审核用的是**你自己填的 API Key**，**审完立即丢弃，不保留记录**。
- 状态流：**草稿 → 提交审核 → 已发布 / 驳回**。**只有审核通过的卡才能发布**。
- **业务不通过**（内容问题）：这不是系统故障，按页面给出的**具体理由**改好，**再重新提交审核**。
- **审核系统异常**（系统问题）：**不是你的卡被拒**，稍后重试即可，Key 与内容都不用改。

### 必读的已知限制

> **审核按前 4 万字符抽检，超出部分已截断——这不等于全文过审。**
> 也就是说，被抽到的内容会审到位，**没抽到的长文/知识库不会逐字审**；
> 发布是**你的责任**，请勿借抽检范围放置违规内容。

- 管理员发布的卡**免审**，但同样**留痕**、同样可被下架。
- 审核会**抽查知识库**，但受上面 4 万字符的截断限制。

## 六、从已有卡改编

**入口**：在**已发布的卡**详情页点「**改编**」。

- 系统会**复制这张卡**为你的**新草稿**，你只改想改的部分即可。
- 为了省流量，**只上传你改动的那部分文件**（不动的内容不会重复上传）。
- 改编出来的卡是**你自己的**，**不会**带着原作者的账号信息。
- 改编产物同样要**过审核**，限制口径与普通制卡完全一致。

## 七、发现不合适的内容

每张卡都有**举报**入口。举报会记录下来，**管理员复核时能看到**；下架后该卡不再出现在公开广场，
但**内容与举报记录都会保留**，可随时恢复。感谢你帮忙看着广场。

## 八、平台的限流口径（如实说明）

平台按**频率**做保护，可能出现「**服务器请求过于频繁（限的是频率，不是你的卡），请稍等约 1 分钟再试**」：

- 限的是**频率，不是你的卡**；
- **稍等约 1 分钟**再试即可，无需改任何设置；
- 浏览、下载、制卡偶尔变慢属于此类保护，不代表服务坏了。

> 排查到具体现象请对照 [05 · 常见问题与排障对照表](05_常见问题与排障对照表.md)。
