# 02 · 配置 API Key

> 覆盖：Key 填在哪里、去哪里拿、Key 无效 / 过期 / 余额不足分别怎么办。
> 报错口径统一见 [常见问题与排障对照表](05_常见问题与排障对照表.md)。

## 一、API Key 是什么

Firefly 本身**不带 AI 大脑**——它调用一个 **AI 服务**来生成回复。你需要填入这个服务的
**钥匙（API Key）**，它才能说话。默认对接 **DeepSeek 开放平台**。

- Key 由你自己在服务商那里**申请**，按你的用量计费，**费用直接付给服务商**，与 Firefly 无关。
- 你的 Key **只保存在本机**（本机的配置文件里），**不会上传给 Firefly 的服务器**。
- 一台设备填一次即可，之后各角色卡共用同一个 Key。

## 二、填在哪里（电脑 / 手机一样）

1. 回到**首页**，点右上角 **⚙（设置）**。
2. 在 **「API Key」** 输入框里，粘贴你申请到的、**以 `sk-` 开头**的一长串字符。
3. 点 **「保存 Key 与连接设置」**。

> **留空 = 保留原来的 Key**（不是清空）。想替换就粘贴新的再保存。

设置页分四组卡片：**账号与连接 / 模型与速度 / 外观 / 数据**。除 API Key 外，改动会**自动保存**。

## 三、去哪里拿 Key（默认 DeepSeek）

1. 打开 **DeepSeek 开放平台**（网址：`platform.deepseek.com`），注册 / 登录。
2. 在平台的「API Keys」页面**创建一个 Key**（以 `sk-` 开头），复制保存好——
   多数平台**只完整显示一次**，关掉页面就看不到了。
3. 在该平台**充值**（或确认有可用余额 / 免费额度）。
4. 回到 Firefly 的设置页粘贴并保存。

> 想用别的服务商？在 **设置 →「模型与速度」** 里可以把 API 供应商改成「自定义」，
> 分别设置接口地址、Key 与模型。**自建 / 第三方服务商**的 Key 也从那边对应的控制台获取。

## 四、Key 出问题了怎么办

### 1. 提示「你的 API Key 无效或已过期」

- **是不是你的问题**：是 Key 本身的问题，但**不是你操作错了**——Key 可能被删除、被平台停用，或复制时少了字符。
- **下一步**：回到 **设置 → API Key**，重新粘贴一遍完整 Key（注意别带多余空格、别漏掉 `sk-` 前缀），保存后再试。
- **本机对话数据与角色卡不受影响**，换好 Key 即可继续。

### 2. 提示「你的上游账号余额不足」

- **是不是你的问题**：是**你的上游账号余额**问题了，与角色卡、本机数据无关。
- **下一步**：到你所用**供应商的控制台**充值（默认就是 DeepSeek 开放平台），充值后**无需改任何设置**，直接再发一次消息即可。

### 3. 没填 Key 就发消息

应用会提示你先去设置里填 Key。按上面「填在哪里」做一次即可。

### 4. 自建 / 第三方服务商连不上

- **可能原因**：接口地址写错，或该地址本身无法访问。
- **下一步**：到 **设置 →「模型与速度」** 核对接口地址是否正确；若地址无误仍不通，
  多半是**对方服务临时波动**，稍后重试（详见排障表「本地网络」一行）。

## 五、想换模型 / 调速度

在 **设置 →「模型与速度」** 里：

- 默认真接 DeepSeek 官方，**填好 Key 即用**；
- 展开「自定义」可分别调整**检索 / 分析 / 回复 / 组织**四个阶段的模型与思考档位；
- 追求省钱省时可把思考档位调低，追求更稳的推理可调高——**改完自动保存**。

> 模型怎么选不是必须的：默认档位对大多数人是合适的。不确定就**保持默认**。

## 六、安全与隐私（先说清楚）

- Key **只存本机**，不上传；服务端看不到你的 Key。
- 做角色卡时的**审核**会用你填的 Key 调一次模型——审核完成**立即丢弃**，不保留记录。
- 把 Key 发给别人等于把钥匙交出去：**不要把 Key 截图发到群里或贴在反馈里**。
  反馈时如需要提供，请先确认没有泄露。
