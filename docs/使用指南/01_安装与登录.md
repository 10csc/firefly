# 01 · 安装与登录

> 覆盖：电脑（Windows）安装包怎么装、手机（安卓）APK 怎么装、第一次登录 / 注册、登录过期怎么办。
> 想直接查报错，看 [常见问题与排障对照表](05_常见问题与排障对照表.md)。

## 一、电脑（Windows）安装

**装什么**：官方发布的 `firefly-setup.exe`（Windows 一键安装包）。

1. 从**官方发布的下载页**拿到 `firefly-setup.exe`（请认准官方渠道，别用来路不明的安装包）。
2. 双击运行，按提示一路「下一步」装完。
3. 装好后，**桌面和开始菜单**都会出现 Firefly 快捷方式，双击即启动。
4. 启动后浏览器会**自动打开**一个本机页面（地址是 `localhost` 开头）。如果没自动打开，
   手动在浏览器里访问 `http://localhost:8765` 即可。

- 数据放在**安装目录旁的一个数据文件夹**里（对话、记忆、手账、Key 都在这里）。
  **覆盖安装新版本前，建议先把这个文件夹整体备份一份**。
- 只绑本机，**仅你自己的电脑能访问**；别人从网络上连不进来。

### 端口被占用怎么办

如果启动后页面打不开，通常是本机 `8765` 端口被别的程序占了。关掉占用的程序再启动一次即可
（多数情况是上一次的 Firefly 没退干净）。仍不行请反馈，我们帮你定位。

## 二、手机（安卓）安装

**装什么**：官方发布的 `firefly.apk`。

1. 从**官方发布的下载页**拿到 `firefly.apk`。
2. 传到手机上安装（手机浏览器直接下载安装，或用数据线 `adb install`）。
3. 第一次打开会弹出「允许安装未知来源应用」之类的系统提示，允许后继续。
4. 首次启动会花 **几秒**做初始化（加载设定资料），随后进入首页。

**适配要求（重要，先看再装，避免装不上）**：

| 项目 | 要求 |
|---|---|
| 安卓版本 | **Android 8.0 及以上** |
| CPU 架构 | **仅支持 64 位**（现代手机 `arm64-v8a` / 模拟器 `x86_64`）；**32 位老设备装不了** |
| 存储空间 | 建议 **≥200MB**（安装包约 49MB，另加运行时数据） |
| 网络 | 需要联网（调用你在设置里填的 AI 服务） |
| 权限 | 只申请联网权限，没有其他权限 |

**几个正常现象，不用慌**：

- **锁屏或切后台后回来没反应**：系统可能把 App 冻结了，**回到前台会自动恢复**，不用重开。
- **手机安装的是独立版**：不依赖电脑，电脑关机也能用。
- **卸载 App 会清空全部数据**（对话 / 记忆 / 手账 / Key）。**覆盖升级则数据保留**——
  换手机或准备卸载前，先用 App 内的导出功能备份。

## 三、第一次登录 / 注册

登录和注册**只用于「角色卡平台」**（逛广场、做卡、发布）。**本地聊天不需要登录**，
不注册也能正常和角色聊天。

**注册需要**（缺一不可）：

1. 一个 **QQ 邮箱**（其他邮箱不行）。
2. 密码**至少 8 位**。
3. **已加入官方 QQ 群**（群号 **1097936258**），并填入群号作为邀请码。
4. 邮箱收到的**验证码**（5 分钟内有效）。
5. 安装在**官方渠道下载的 App**（每个安装只能注册**一个**账号）。

**注册流程**：在登录页点「注册」→ 填邮箱 → 点「发送验证码」→ 去 QQ 邮箱收码填回 →
填密码与群号 → 提交。注册成功后用邮箱 + 密码登录。

- **一个安装只能注册一次**：同一台设备装好后就绑定了首个注册的账号，重复注册会被拒绝。
- **收不到验证码**：先看垃圾邮件 / QQ 邮箱的「订阅邮件」分类；60 秒内不能重发，稍等再点。
  若始终收不到，请反馈（大概率是发信通道的问题，不是你的操作问题）。

## 四、忘记密码

在登录页点「忘记密码」→ 输入**已注册的 QQ 邮箱** → 发送验证码 → 收到后填验证码 + 新密码即可重置。
重置成功后，**其他设备上已登录的会话会被清掉**，需要用新密码重新登录。

> 说明：为避免暴露"某个邮箱是否注册过"，**未注册的邮箱与验证码错误会给出同样的提示**。
> 这不是故障，是产品有意为之。

## 五、登录过期了怎么办

你会看到类似 **「登录已过期，请重新登录（你的本地数据与角色卡不受影响）」** 的提示。这**不是你操作错了**，也**不影响你本机的对话数据与角色卡**。

**下一步**：回到登录页，用原来的邮箱 + 密码重新登录一次即可。若忘了密码，按上面「忘记密码」重置。

- 重新登录**只影响平台相关的操作**（逛广场 / 做卡 / 发布）；本机聊天一切照旧。
- 反复被踢下线，多半是密码在别处改过，或在多台设备交替登录，重新登录即可。
