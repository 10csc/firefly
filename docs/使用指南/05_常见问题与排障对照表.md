# 05 · 常见问题与排障对照表

> 这是整套指南里**最该先看**的一篇。遇到提示时，先在下面表格里找到**最像的那一行**，
> 照「下一步做什么」做即可。**绝大多数情况不是你的设备或操作的问题。**

## 一、先做这三件事

1. **看提示的措辞**：提示里说的是「太频繁 / 超时 / 服务波动 / 余额 / Key / 网络 / 登录 / 上限 / 审核」中的哪一个？
   一个字差别，原因完全不同——请**按字面**对到下面表格的对应行，**不要把不同的事混为一谈**。
2. **能重试的先重试一次**（多数是临时波动，等一会儿再发一次就好）。
3. **仍不行就反馈**：带上**诊断包**（在本机生成，不经过服务器），并**照抄提示原文**、说清当时在做什么。

## 二、排障对照表（现象 → 是不是你的问题 → 下一步）

| # | 你会看到（现象） | 是不是你的问题（原因） | 下一步做什么 |
|---|---|---|---|
| 1 | 「**这是上游接口的临时限制**，不是你的卡或操作的问题：约 1 分钟后会自动重试」 | 这是**上游接口的临时限制**，**不是你的卡或操作的问题** | 约 **1 分钟后会自动重试**，**无需改任何设置**；也可稍等手动再发一次 |
| 2 | 「**这次生成超过了本轮时间上限**，不是你那边的问题：稍等再发一次即可」 | 这次生成超过**本轮时间上限**，**不是你那边的问题** | **稍等再发一次**即可 |
| 3 | 「**上游服务临时不可用**，不是你那边的问题：稍后重试即可，不必改 Key」/「**上游服务波动中**，不是你那边的问题：稍等约 1 分钟再试」 | **上游服务临时不可用**，**不是你那边的问题** | **稍后重试**，**不必改 Key 或设置** |
| 4 | 「**你的上游账号余额不足**：请到所选供应商的控制台充值后重试（与本机数据、角色卡无关）」/「你的上游账号**余额不足**，无法完成审核；请充值后重试」 | 你的**上游账号余额不足**；**与本机数据、角色卡无关** | 到**你所选供应商的控制台充值**后重试 |
| 5 | 「**你的 API Key 无效或已过期**：请到设置里重新粘贴 Key（本机对话与角色卡不受影响）」/「Key **无效或已失效**，请检查后重试」 | 你的 **API Key 无效或已过期**（可能被删 / 被停用 / 复制不全） | 到**设置**里重新粘贴 Key；**本机对话与角色卡不受影响** |
| 6 | 「**本机网络或接口地址连不上**：请检查网络后重试（不是账号问题，数据不受影响）」 | **本机网络或接口地址连不上**；**不是账号问题**，数据不受影响 | **检查网络**后重试；若用自建服务商，核对接口地址 |
| 7 | 「**登录已过期，请重新登录（你的本地数据与角色卡不受影响）**」 | 登录状态过期 | **重新登录**；**你的本地数据与角色卡不受影响** |
| 8 | 「**服务器请求过于频繁（限的是频率，不是你的卡），请稍等约 1 分钟再试**」 | 服务器请求过于频繁（限的是**频率**，**不是你的卡**） | **稍等约 1 分钟**再试 |
| 9 | 「**最多安装 5 张**广场角色卡…」/「**图片过大（当前 …MB，上限 10MB）；请压缩后再传**」/「标签最多 20 个」等 | **数量或体积达到上限**（提示里会给出**当前值与上限**） | 按提示**卸载 / 删减 / 压缩**后重试；或换更小 / 更少的素材 |
| 10 | 「**审核未通过**：按下面的理由改好，改完必须重新提交审核。」 | 这是**对内容的结论**，**不是系统故障** | 按页面给出的**具体理由**修改后**重新提交审核** |
| 11 | 「**审核服务异常**（…），可重试。」 | 这是**系统问题**，**不是你的卡被拒** | **稍后重试**即可（**Key 与内容都不用改**） |
| 12 | 「审核按**前 4 万字符抽检**，已截断…**这不等于全文过审**」 | **这不是报错**，是一条**说明** | 明白「截断 ≠ 全文过审」，**长内容请自行把关**后再发布 |
| 13 | 提示里带「**合成失败**」/「**备份写入失败**」字样 | **本机程序环境不完整 / 缺文件 / 写盘失败**；**不是账号或网络问题** | 按提示**补齐环境**（如语音模型），或**换一个可写的目录**后重试 |
| 14 | 「**发生了未归类的问题**：请重试一次；仍失败请在「反馈」里附诊断包」 | 发生了**未归类的问题** | **重试一次**；仍失败就到「**反馈**」里附**诊断包**（见第三节） |

> 说明：不同版本界面上的提示措辞可能略有出入，但**含义一一对应上表**。
> 若你看到的提示**不在上表任何一行**，请按第 14 行处理并反馈。

## 三、怎么反馈（附诊断包）

1. **导出诊断包**：手机端首页左上「**✉ 反馈**」→「**导出诊断包**」；电脑端首页左上「**反馈**」→ 同样导出。
   - 诊断包**在你本机生成，不经过服务器**；有分享面板就直接发给我们，否则到下载目录取文件。
2. **照抄提示原文**：把界面上的提示**一字不差**抄下来（比"它报错了"有用得多）。
3. **说清三件事**：当时在做什么（聊天 / 逛广场 / 做卡 / 语音）、什么时候开始、是否每到这一步都复现。
4. 其他联系方式：**QQ 群 1097936258**；或按反馈页里的 GitHub / 邮箱联系。

> **不要**在反馈里附上你的 **API Key** 或账号密码；需要排查时我们会另说。

## 五、几条最容易弄混的（重点澄清）

- **「太频繁」有两种**：第 1 行是**上游**（AI 服务）的临时限制；第 8 行是**平台服务器**的频率保护。
  两者都**不是你的错**，都要**稍等再试**，但**来源不同**、**重试等待也不同**。
- **「余额」和「Key 无效」是两回事**：余额不足 => **充值**（第 4 行）；Key 无效 / 过期 => **换 Key**（第 5 行）。
- **「审核未通过」和「审核服务异常」是两回事**：前者是**内容结论**，要**改内容重提**（第 10 行）；
  后者是**系统临时故障**，**内容不用改、稍后重试**（第 11 行）。**别把系统故障当成自己被拒**。
- **「审核截断」不是报错**（第 12 行）：它只是提醒你**抽检范围有限**，发布责任在作者。
