# P0 · 致命（16 项）

## A. 安全

### A1 ✅ `/shutdown` 零来源校验 — 一行 HTML 杀死本地进程
`app/server.py:69-74`
```python
if path == "/shutdown":
    self._json({"ok": True, "shutting_down": True})
    _t.Timer(0.3, lambda: shutdown_server()).start()   # 0.3s 后 os._exit(0)
```
`app/shared_http.py:104` 的函数文档自己写着「**各入口的 /shutdown 必须做来源校验（仅本机可触发）**」——规则写了，没执行，全无 `self.client_address` 判定。
**后果**：任意网页 `<img src="http://127.0.0.1:8765/shutdown">` 即可静默杀死进程，未落盘的记忆/手账/对话全丢。
**建议**：`self.client_address[0] in ("127.0.0.1","::1")` 且请求不得携带 `X-Forwarded-For`/`X-Real-IP`。

### A2 ✅ CORS `*` + 本地版零鉴权 = 任意网页可接管本地实例
`app/shared_http.py:52-59`
```python
def _cors_headers(self):
    """...Bearer token 认证 + 无 Cookie，`*` 安全。"""
    self.send_header("Access-Control-Allow-Origin", "*")
```
注释的前提**不成立**：本地版根本没有 Bearer 认证（全仓无 Origin/Referer/token 校验）。作者把「只绑 127.0.0.1」当安全边界，又亲手用 CORS 把它拆掉。
**可被任意网页驱动**：
- `GET /config` 读 Key 前缀（`routes_config.py:258`）
- `POST /set-key` 改 Key（`routes_config.py:53`）
- `POST /set-config` 改 `base_url`（`:161`）→ 后续请求连 Key 一起打到攻击者服务器
- `POST /import-data` 覆盖全部用户数据（`data_export.py:117`；multipart 属 CORS 安全类型，**不触发预检**）

**建议**：Origin 白名单 + `Sec-Fetch-Site` 校验；写端点加一次性 token。

**建议**：nginx 证书 + HSTS，`config.js` 改 https，地址改为构建期注入并 `git rm --cached`。

### A4 更新通道明文且无签名 — 可下发木马安装包
