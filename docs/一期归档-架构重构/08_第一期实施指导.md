## 4. 第一期总验收（DoD）

1. readme 测试集 + 各波新增测试全绿；`sync_frontends.py --check`、`check_version.py` 通过。
2. **新装链路 E2E**：安装 → 注册/登录引导（登录优先）→ 默认 DeepSeek 只粘 SK → 发图 → vision 回复 → 换端登录 → 文字类数据已同步、图片在新设备显示占位。
3. **存量链路 E2E**：旧 `config.json` 启动自动迁移、SK 无感接过；安卓旧版升级后模式切换按钮消失，本地后端失败时自动连服务器后端。
4. **铁律核验**：抓包 + 查文件确认服务器全链路（pipeline.jsonl、requests 表、备份包、同步包、内存中转对象生命周期）无图片字节持久化；conversation 里图片消息只有 `img_id + desc`。
5. **托管链路**：proxy 模式传图经过式（发出即弃）；relay 模式图片不出 APP（占位符由 APP 本地填充）。
6. **降级核验**：自定义供应商（无 thinking/caps）跑通一轮 chat；vision-exp 不可用时图片消息降级为手填描述/占位。
