# 表情包选择器 - 模块规格 V2

## 职责

表情包注册表 + 按分类随机选图。纯代码层，不调 LLM。

标记替换（[sticker] → 图片消息）由 composer 负责，本模块不参与。

## 接口

### pick_sticker(category)

从指定分类中随机选一张表情包。

```
输入: category（"强势"|"弱势"|"无偏向"|"喜欢"）
输出: StickerEntry | None
流程: 审查(category合法性) → 匹配(按分类筛选) → 输出
```

降级：非法 category → WARNING + 修正为"无偏向"。分类无图 → 降级到"无偏向"类。
