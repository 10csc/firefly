## 文档分类

- `概念/`：解释系统是什么、为什么这样设计，不写逐步操作。
- `操作/`：完成一项具体工作的步骤、前提、验收和回滚。
- `参考/`：协议、字段、命令、约束和测试基线。
- `决策/`：重要且不易回退的架构决定；旧决定由新 ADR 取代，不改写历史。
- `错误总结/`：真实事故和改进措施，保留事故语境。
- `使用指南/`：面向最终用户，不依赖开发背景。

具体规则见 [文档治理](文档治理.md)。
