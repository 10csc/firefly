# Firefly 项目文档

## 当前架构（V5，0.8.1）

详细的交互式架构图见根目录 **`项目架构图/index.html`**（离线双击打开：三端拓扑 / 对话流水线 / 模块矩阵 / 路由地图 / 发布链 / 安全体系）。

```
POST /chat → routes → orchestrator.handle_chat()
  │  前置审查（空/超长直接降级）
  ├─ llm_retriever.retrieve()  → 知识压缩摘要（haruno 跳过，失败不阻塞）
  ├─ analyzer.analyze()        → intent / fact_check / summary
  ├─ polisher.polish()         → 多条文本消息（可带识图）
  ├─ organizer.organize()      → 表情包 / 旁白（失败只丢装饰不阻塞文本）
  └─ context_manager + conversation_store 写历史（pipeline.jsonl 观测）
```

## 部署状态口径（2026-09-18 实测更正）

> 此前多份文档写"08-25 与 09-15 修复均未部署"，**与实测不符**，以下为更正后的口径：

- **2026-08-25 安全修复：已部署上线**（2026-09-13 那次部署带入）。实测依据：线上 `sessions` 表 22 条 token 全部为 64 位 sha256 哈希；`settings.schema_version = 3`；`auth.py`/`db.py`/`download_server.py`/`download_lib.py` 与仓库逐字节一致。
- **2026-09-15 两批修复：未部署**。但实际只缺两个文件：`server/download_page.py`（缺 A4 直链信任校验）与 `app/shared_http.py`（缺 A1/A2 本地信任边界，对服务器模式无影响）；其余文件已随 09-13 部署生效。
- **对外发布的安装包（`firefly-setup.exe` / `firefly.apk`）：停留在 2026-08-23**，缺增量同步模块与 08-25 之后的所有修复，**需要重建发布**（实测：包内搜不到 `local_origin_ok`，且没有 `sync.js`）。
