## 二、systemd（主服务）新增的环境变量

按**灰度顺序**加，不要一次开到底：

```ini
# 第一步（部署当天）：只启用解密能力，仍接受明文
Environment=FIREFLY_ENC_ENABLED=1
Environment=FIREFLY_ENC_KEY=/opt/firefly/keys/session_priv.pem

# 第二步（确认所有在用的客户端都已升级，且 stats 里 plain 计数趋 0 之后）：
# Environment=FIREFLY_ENC_REQUIRED=1
```

观察口径：`session_crypto.stats()` 的 `enc / plain / fail / rejected` 计数
（`/admin` 或日志里看一眼；`plain` 长时间不归零说明还有老客户端在用，**别开 REQUIRED**）。

## 四、部署后的六项验证（`docs/服务器管理规范.md` §4.5 同口径）

1. `GET /version.json` 与 `GET /update-manifest` 都返回新版本、`apk.url` 是 https Gitee 直链；
2. `curl -I https://…/firefly.apk` 的 `Content-Length` 与清单 `assets.apk.size` 一致；
3. **exe 直链不再指向 v0.8.1**（这是 P0-1 的直接判据）；
4. `/download/` 页面显示的版本号与新清单一致；
5. **加密观测**：用带信封的请求打一次（`tests/test_session_crypto.py` 里的 `client_env()`
   可以直接生成），确认返回 200 且 `/admin` 的 `enc` 计数 +1；再用明文请求打一次，确认仍是 200；
6. 安卓"服务器模式"登录后随便点一个功能，确认没有 401（说明解密入口接对了）。
