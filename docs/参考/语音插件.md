# 语音插件

语音是某条消息的附属产物，不是新的消息类型。用户长按消息选择“转语音”，生成结果写到当前角色的语音缓存，随后以音频条播放。

## 架构

| 平台 | 合成位置 |
|---|---|
| Android | Kotlin + ONNX Runtime，复用 WebView 桥 |
| PC | 独立子进程；空闲退出并归还模型内存 |
| Python 服务 | 只负责状态、任务调度、文件与 API，不承载 Android ONNX |

模型本体放在 `$FIREFLY_DATA_DIR/voice/`，不进入 `user_data` 备份和同步。音频缓存注册为运行期数据，清理历史或撤回时同步截断。

## 接口

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/voice/plugin-status` | 安装、启用、资源和任务状态 |
| POST | `/voice/plugin-install` | 下载并校验模型 |
| POST | `/voice/plugin-enable` / `disable` | 启用或停用 |
| POST | `/voice/plugin-uninstall` | 删除模型，不删除已生成音频 |
| POST | `/tts` | 为指定 `seq` 幂等生成语音 |
| GET | `/voice/{mode}/v{seq}.wav` | 播放音频 |

模型文件必须校验尺寸和 SHA-256；单个下载失败不能留下半成品。插件不可用时静默退回纯文字，不阻塞聊天。

## 当前风险

- Android 首次运行仍需人工确认系统语音和播放链路。
- PC 长句存在偶发过早收敛，生成音频可能截短；当前以重新生成降级。
- 自动测试不能替代真机音频验收。

模型下载地址、凭据位置和历史实测数据已归档。凭据只放用户环境变量或受限文件，不写文档、日志和仓库。
