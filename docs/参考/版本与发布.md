# 版本与发布

本页定义整包版本合同和发布证据。发布权限与热更新边界见 [发布规则](发布规则.md)，
具体打包命令见 [本地开发与构建](../操作/本地开发与构建.md)。

## 版本格式

- 用户可见版本使用 `x.y.z` 纯数字点分。
- Android `versionCode` 必须严格大于已发布的上一版。
- 正式用户只接收稳定版；预发布版不得污染 Gitee 的“最新 Release”判定。
- 发行资产名固定为 `firefly.apk` 与 `firefly-setup.exe`，文件名不携带版本号。

## 单一事实源

本地版本由 `tools/check_version.py` 校验，release/deploy 必检项为：

| 位置 | 字段 |
|---|---|
| `app/core/config.py` | `APP_VERSION` |
| `app/static/js/update.js` | `CURRENT_VERSION` |
| `android/app/build.gradle.kts` | `versionName`、`versionCode` |
| `package/firefly.iss` | `AppVersion` |

`server/update.json` 是最新已发布整包的唯一线上事实；`server/version.json` 是兼容投影，禁止手写第二套版本。
已发布产物的尺寸与 SHA-256 记录在 `release_manifests/release_manifest_<version>.json`。

## 三档门禁

| Profile | 用途 | 主要约束 |
|---|---|---|
| `dev` | 日常开发 | 本版本源一致，允许开发版本高于线上 |
| `release` | 构建并准备发布 | 候选台账存在，产物字节与台账一致，`versionCode` 大于已发布版本 |
| `deploy` | 发布后、部署前的本地预检 | 本地已发布投影、资产台账和本地产物一致；它不能证明线上 |

命令：

```powershell
python tools/check_version.py --profile release
python tools/check_version.py --profile deploy
```

同版本已进入发布台账后，产物不可替换。若本地重建得到不同字节，只能进入新版本，不能覆盖旧资产。

`deploy` 只读工作区中的发布投影，不访问服务器。线上是否收到同一资产必须另行做 HTTP/SSH 只读回读，
并把时间、来源和关键哈希写入部署记录；本页不把本地预检结果命名为“线上 verified”。当前生产基线见
[生产只读基线（2026-10-27）](../操作/生产只读基线-2026-10-27.md)。

## 完整发布顺序

以下外部上传、资产更新与生产回读属于 S2 发布流程；任何一步都必须先获得用户明确授权。

1. 获得用户明确的发布授权，确定新版本号和发布范围。
2. 同步修改全部本地版本源；未经授权不提前 bump。
3. 运行活动测试基线；失败必须有根因和处置，不能用旧测试数量替代结论。
4. 构建 PC 与 Android 产物，清理任何测试用户数据。
5. 运行 `python tools/release_manifest.py build` 生成不可变台账。
6. 运行 `check_version --profile release`、前端/后端镜像检查、热更新声明检查和包内验收。
7. 上传到 GitHub 与 Gitee，逐项确认 tag、Release 和两个资产都能回读。
8. 更新 `server/update.json` 与兼容投影并签名；部署前运行 `check_version --profile deploy`。
9. 更新服务器下载兜底副本，分别回读两处版本投影、下载解析和实际字节。
10. PC 与 Android 实际启动，确认更新检查、下载和覆盖安装链路。

任一阶段失败都停止后续阶段；不得先对用户宣布成功再补验证。

## 跳版本与数据迁移

- 版本比较按数值逐段进行，允许用户从旧版本直接升级到当前稳定版。
- 数据迁移按文件状态判断，不按“刚好经过哪个版本”判断，因此必须幂等。
- 迁移先于默认文件复制，避免默认文件挡住用户数据。
- 迁移优先使用原子换入或“目标不存在才移动”；不得静默覆盖用户目录。
- 安装器保留 `user_data`；Android 覆盖安装依赖稳定签名和递增 `versionCode`。

## 包内验收

发布前必须在源目录、Android assets、APK 内 `app.imy` 之间核对前端实际字节，并验证：

```powershell
python tools/sync_frontends.py --check
python tools/check_backend_sync.py --check
python tools/check_apk_manifest.py android/firefly.apk allowBackup usesCleartextTraffic
python tools/check_apk_frontend.py
python tools/check_no_secrets.py --worktree
```

旧测试与旧审计报告已归档，不作为当前发布证据；当前可执行基线见 [测试基线](测试基线.md)。
