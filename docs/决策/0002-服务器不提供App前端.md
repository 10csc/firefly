# ADR 0002：服务器不提供 App 前端

- 状态：accepted
- 日期：2026-10-27

## Context

Firefly 本地版拥有完整 App UI；服务器账号和角色卡平台也需要 Web 页面。历史上把 App 前端镜像到服务器，造成两套产品边界混淆、生成物漂移和部署风险。

## Decision

- 服务器只提供 API、登录和独立角色卡平台。
- `/index.html`、`js/bundle.js`、App 面板和 App 样式在服务器不可达。
- `app/static/` 只同步到 Android 本地资源；不得镜像到 `server/frontend/`。
- 平台前端使用独立 bundle 和白名单资源。

## Consequences

平台与 App 需要分别构建和部署，平台改动不受 App 热更新覆盖。这是有意的边界，防止服务器重新变成 App 分发副本。
