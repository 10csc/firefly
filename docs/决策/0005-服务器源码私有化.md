# ADR 0005：服务器源码私有化

- 状态：accepted
- 日期：2026-10-28

## Context

`server/` 包含生产入口、部署脚本和运维实现，历史上只通过 `.gitignore` 留在本地，既没有公开仓版本边界，也没有可审计的服务器源码快照。把生成物、备份、数据库或凭据一并提交会扩大泄露面；只依赖未跟踪目录又无法确认线上来源。

## Decision

- 公开主仓不包含 `server/`；`.gitignore` 中的 `/server/` 必须保留。
- 服务器源码进入受控私有仓库 `10csc/firefly-server-private`，首份脱敏快照为 `913c2a2`。
- 私有仓库只保存源码、必要配置模板和构建所需资源，不保存环境变量、token、数据库、日志、备份、缓存或真实用户数据。
- 生产部署仍按变更清单逐文件传输；禁止从未提交的本地工作区全量同步。
- 服务器仍只提供 API 与角色卡平台，不提供 App 前端；服务器源码私有化不改变这一产品边界。

## Consequences

主仓可以独立克隆和审计，不暴露生产实现；服务器变更需要同时在私有仓留存版本，并继续执行单文件部署和回滚检查。公开主仓无法直接验证私有实现，公开侧测试只覆盖可分发代码，涉及 `server/` 的测试必须明确跳过或在私有仓执行。
