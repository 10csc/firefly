# ADR 0003：签名累积热更新

- 状态：accepted
- 日期：2026-10-27

## Context

客户端需要在不重建整包的情况下修复紧急 bug。普通 HTTP 下载或只覆盖少量 Python 文件会让中间人注入、包残缺和旧新代码混用成为真实风险。

## Decision

- 每个补丁清单使用 RSA-2048/SHA-256 签名。
- 补丁按 serial 单调累积，后续 serial 包含前序 serial 的全部差异。
- Python 包按完整闭包发布，不能只覆盖单个 `__init__.py` 或少量兄弟模块。
- 热更新只修 bug，不发布新功能，不删除文件。
- 底座版本变化后，旧补丁线失效。
- 发布前必须从干净底座应用、验签、导入并运行真实链路测试。

## Consequences

补丁体积会增加，但可重建、可验证、可回退。发布流程必须以完整包和真实测试为准，不能把“上传成功”当成“设备已生效”。
