# ADR 0004：文档按内容类型治理

- 状态：accepted
- 日期：2026-10-27

## Context

项目文档曾同时承担当前规范、实施日志、审计证据、交接计划和历史方案。结果同一事实多处维护，旧测试数、旧入口和旧状态持续误导执行者。

## Decision

活动文档按 Concept、Task、Reference、Decision 分目录；错误记录和用户指南独立。活动页描述当前事实，历史过程移入可恢复归档。链接、测试引用和权威状态必须可核验。

## Consequences

每次改动需要同步对应概念、参考或操作页；历史内容多一步归档，但不再污染当前入口。治理规则见 [文档治理](../文档治理.md)。
