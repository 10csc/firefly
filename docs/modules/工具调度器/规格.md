# 工具调度器 - 模块规格 V2

## 职责

规划器和工具之间的桥梁。接收规划器的 `tools` 数组，执行实际工具调用。

不调 LLM，纯代码层。标记替换（[sticker]→图片消息）由 composer 负责，调度器不参与。

## 接口

### pre_dispatch(tools, sticker_style)

回复前执行。调用气泡更新器和表情包选择器。

```
输入:
  tools: [{"tool":"bubble","suggestion":"科幻风格"}, {"tool":"sticker","suggestion":"可爱"}, ...]
  sticker_style: 解码器产出的表情包风格偏好（"强势"|"弱势"|"无偏向"|"喜欢"）

输出: PreResult
  - bubble: BubbleResult | None
  - tools_summary: str（注入回复模块 prompt）
  - picked_sticker: StickerEntry | None（注入 composer）
```

## Bubble 子代理

规划器 suggestion → 气泡 key 匹配。从 `bubble_updater.get_all_bubbles()` 读取单一数据源的 `keywords` 字段做关键词匹配。

```
suggestion("科幻风格") → 匹配 bubble_culture.keywords(["科幻","科技","中性","默认","日常"]) → apply_bubble("bubble_culture")
```

## Sticker 子代理

规划器 suggestion → sticker 分类映射 → `pick_sticker(category)` 随机选图。

```
suggestion("可爱/打招呼") → 映射"无偏向" → pick_sticker("无偏向")
suggestion("害羞/安慰")   → 映射"弱势"   → pick_sticker("弱势")
suggestion("出击/强势")   → 映射"强势"   → pick_sticker("强势")
```

## 流程

```
pre_dispatch:
  审查(tools类型) → 遍历 tools → bubble(匹配→apply_bubble) / sticker(映射→pick_sticker)
  → 生成 tools_summary → PreResult
```

## 降级

| 场景 | 降级 |
|------|------|
| tools 非 list | 视为 [] |
| suggestion 无匹配气泡 | WARNING + 不切换 |
| sticker 分类无图 | 降级到"无偏向" |
| 工具执行异常 | ERROR + 不中断 |
