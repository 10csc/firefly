# 回复生成器 - 模块规格 V2

## 职责

根据规划器的 tone + direction 指引，结合状态描述和对话历史，生成自然的流萤回复文本。分句由 composer 负责，回复器只产出原始文本。

模型: Flash + Think High (`reasoning_effort="high"`)

## 角色设定

从 `app/assets/character/{core,identity,experience}.md` 加载三件套，注入 system prompt：
- **core.md**：基础设定、身体情况、故事、感情、人生观
- **identity.md**：与星核猎手成员关系、做过的事、习惯与喜好
- **experience.md**：与开拓者的记忆、对他的了解

`reload_character()` 支持运行时热重载 md 文件。

## 输入

```python
@dataclass
class ReplyInput:
    state_desc: str       # 解码器 reply_context
    tone: dict            # {"base":"温柔","modifiers":["关心"],"intensity":"克制"}
    direction: str        # 自然语言方向指引（来自规划器）
    recent_history: list  # 最近对话
    user_input: str       # 开拓者当前消息
    tools_summary: str    # 工具调度结果描述（含 [sticker] 使用提示）
```

## 输出

```python
@dataclass
class ReplyOutput:
    raw: str              # LLM 原始回复文本（含 [sticker] 标记，待 composer 分句）
```

## 流程

```
审查(ReplyInput合法性) → 构建prompt(角色三件套+tone+direction+tools_summary)
  → 注入历史对话 → LLM(Think High) → 输出 raw 文本
```

## 降级

| 场景 | 降级 |
|------|------|
| LLM 调用失败 | raw="" |
| state_desc/direction 为空 | 填充默认描述 |
