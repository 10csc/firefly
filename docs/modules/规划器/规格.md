# 规划器 - 模块规格 V2

## 职责

调度中心。根据对话历史和状态描述推断因果关系、决定工具调用、给出回复方向指引。规划器不生成回复文本——你是在给"另一个自己"写方向指引。

模型：Flash + Think High (`reasoning_effort="high"`)

## 输入

```python
@dataclass
class PlannerInput:
    decoded_summary: str      # 状态解码器 summary
    recent_history: list      # 最近对话 [{"role","content"}, ...]
    tools_menu: str           # 可用工具自然语言描述（TOOLS_MENU）
    user_input: str           # 开拓者当前消息
    stop_reason: str          # 来自 JudgeResult
    sticker_frequency: str    # 表情包频率："经常"|"偶尔"|"几乎不"
    sticker_style: str        # 表情包风格："强势"|"弱势"|"无偏向"|"喜欢"
```

## 输出

```python
@dataclass
class PlannerOutput:
    tools: list      # [{"tool":"bubble","suggestion":"科幻风格"}, ...]
    tone: dict       # {"base": "日常|温柔|害羞|认真|困惑|战斗", "modifiers": [...], "intensity": "克制|自然|强烈"}
    direction: str   # 自然语言回复方向指引
```

## 可用工具（TOOLS_MENU）

- **bubble（聊天气泡）**：换聊天框风格。开拓者要求或情绪明显变化时用。
- **sticker（表情包）**：发一张表情。不要太频繁，感觉对了就发。

## 流程

```
审查(PlannerInput合法性) → 构建prompt(性格+状态+历史+事件+工具菜单)
  → LLM推理(Think High) → 解析JSON → 验证+降级 → 输出
```

## 降级策略

| 场景 | 降级 |
|------|------|
| LLM 调用失败 | 返回默认输出（日常/自然/空工具） |
| JSON 解析失败 | 同上 |
| tone.base 非法 | 降级为"日常" |
| tone.intensity 非法 | 降级为"自然" |
| direction 为空 | "根据对话自然接话。" |
| tools/tone 缺失 | 默认值填充 |
