# 状态更新器 #1 - 模块规格 V3

## 架构

状态更新拆为两个独立模块，三路并行调用：

```
MoodUpdater (心情)     StateUpdater (关系/紧张/主动性)
     │                        │
     ├──────── 并行调用 ───────┤
     │                        │
     └────── merge_moods ──────┘
```

## StateUpdater

### 职责
计算 relationship/tension/initiative 三个数值的 delta。不处理 mood（mood 透传不修改，由 MoodUpdater 并行处理后合并）。

### 输入
| 字段 | 说明 |
|------|------|
| `user_input` | 用户输入原文 |
| `judge_result` | JudgeResult 实例（来自规划判断器） |
| `current_state` | 当前 `{"mood": list, "relationship": float, "tension": float, "initiative": float}` |
| `energy` | 上下文管理器提供（只读透传） |

### 输出
`StateResult` — 透传 JudgeResult + 更新后的 state dict + energy

```python
@dataclass
class StateResult:
    result_mode: str
    stopped_at: int
    stop_reason: str
    reply_direct: dict | None
    execution_plan: dict | None
    state: dict          # mood(透传)/relationship/tension/initiative
    energy: int
```

### 敏感点分类
| 等级 | 触发 | rel_delta | ten_delta |
|------|------|-----------|-----------|
| 极深 | 短命鬼/活不长/病秧子 | -0.8~-1.0 | +15~+20 |
| 重度 | 怪物/兵器/消耗品/工具 | -0.5~-0.8 | +10~+15 |
| 中度 | 被当AI/被迫谈死亡 | -0.1~-0.3 | +3~+8 |
| 轻度 | 不了解事实的攻击(逃兵) | -0.1~-0.2 | +2~+5 |
| 无感 | 客观战场评价 | 几乎不变 | — |

### 正面触发
| 触发 | rel_delta | ten_delta | ini_delta |
|------|-----------|-----------|-----------|
| 真诚关心 | +0.3~+0.5 | -3~-8 | — |
| 日常温暖 | +0.1~+0.3 | -1~-3 | +1 |
| 道歉 | +0.1~+0.2 | -5~-10 | — |
| 浪漫表白 | — | +3~+8 | -0.5~-1 |
| 紧急 | — | +15~+25 | +2 |

### 属性约束
| 属性 | 范围 | 单次 delta 校验 |
|------|------|-----------------|
| relationship | 65-100 | -2.0~+2.0 |
| tension | 0-100 | -30~+30 |
| initiative | 0-100 | -10~+10 |

## MoodUpdater（独立模块）

心情系统已拆为独立模块，详见 [心情更新器规格](../心情更新器/规格.md)。

核心设计：
- **多情绪共存**：6 种情绪（安心/开心/低落/害羞/焦虑/困惑），强度 1-5
- **冲突消解**：开心↔低落、安心↔焦虑 互斥
- **Adder + Decayer 并行**：新增情绪 + 消退情绪 同时进行
- **Decayer LLM 诚意判断**：有效恢复/部分恢复/无恢复，代码执行强度变化
- **负面情绪不归零**：明确行为转变前最低降到 1

## 降级策略
- Delta 非法（JSON 异常/超出范围）→ 保持原 state + ERROR 日志
- API 错误 → 保持原值 + ERROR 日志
- State 边界溢出 → 裁剪到合法范围 + INFO 日志
