# 状态更新器 - 模块规格 V4

## 架构

状态更新拆为两个独立模块，三路并行调用：

```
MoodAdder (新增情绪)     MoodDecayer (消退情绪)     StateUpdater (好感/紧张 raw delta)
     │                        │                        │
     └────────────────── 并行调用(ThreadPoolExecutor) ──┘
                              │
                    merge_moods() + compute_rates() + finalize()
```

## StateUpdater

### 职责
计算 **好感度(affection)** 和 **紧张度(tension)** 的 raw delta（原始增量），由 LLM 判定触发类型。主动性不由此模块处理——见 `finalize()`。

### update() — 产出 raw delta

**输入**：`user_input` + `JudgeResult` + `current_state` + `energy`

**输出**：`StateResult` — 透传 JudgeResult + prev_state（delta 未应用）+ raw delta

```python
@dataclass
class StateResult:
    result_mode: str
    stopped_at: int
    stop_reason: str
    reply_direct: dict | None
    execution_plan: dict | None
    state: dict          # prev_state 副本（delta 未应用，等待 finalize）
    energy: int
    affection_delta: float   # 原始 delta，供 finalize 使用
    tension_delta: float
```

### finalize() — raw delta → 最终 state 合成（纯代码）

由 orchestrator 在 `compute_rates()` 后调用。收口全部合成：

- 倍率应用：`new_affection = prev + affection_delta × rates["affection"]`
- 紧张倍率应用 + 自动消退 `-1.5`
- 主动性培养：用户被动(短消息不提问)→+0.1×ini_rate，用户主导(提问/提议)→-0.1×ini_rate
- initiative 倍率：`compute_rates()` 的 `rates["initiative"]` 已接入，不再"暂不应用"
- 钳位：好感 [0,100]、紧张 ≥0（不设上限）、主动 [0,100]

mood 不由此处理——由 `merge_moods()` 覆盖。

### LLM 判定规则

**好感度变化（affection_delta，-0.8 ~ +0.3）**：
- 真诚关心 +0.2~+0.3，日常温暖 +0.1~+0.2
- 敷衍/冷处理 -0.1，中度辱骂 -0.1~-0.2，重度辱骂 -0.3~-0.5，极深创伤 -0.5~-0.8

**紧张度变化（tension_delta，-5 ~ +25）**：
- 辱骂/攻击不影响紧张度（属于心情范畴）
- 表白/夸赞 +3~+8，害羞话题 +2~+5，紧急求救 +15~+25
- 日常闲聊 -1~-3，关心安抚 -2~-5

### 属性约束

| 属性 | 范围 | 单次 delta 校验 |
|------|------|-----------------|
| affection | 0-100 | -1.0~+1.0 |
| tension | ≥0（无上限） | -10~+30 |
| initiative | 0-100 | 代码层 ±0.1×rate |

### 降级
- LLM 输出异常 → delta 归零 + ERROR 日志
- API 错误 → delta 归零 + ERROR 日志
- finalize 输入非法 → InputRejected
