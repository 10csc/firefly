# 状态解码器 - 模块规格 V1

## 职责

将 StateUpdater 输出的数值 state 转为自然语言描述。纯代码层，确定性映射，不调 LLM。

解码器只知道"什么状态"，不知道"为什么是这个状态"——那是规划器的事。

## 输入

| 字段 | 来源 | 说明 |
|------|------|------|
| `state` | StateUpdater + MoodUpdater + ContextManager | mood/affection/tension/initiative/energy |
| `stop_reason` | PlanningJudge | 事件类型标记 |
| `now` | 系统时间（可选，默认 `datetime.now()`） | 设备本地时间 |

## 输出

```python
@dataclass
class DecodedState:
    time_text: str           # 时间自然语言
    mood_text: str           # 心情自然语言
    affection_text: str      # 好感度自然语言
    tension_text: str        # 紧张度自然语言
    initiative_text: str     # 主动性自然语言
    energy_text: str         # 精力自然语言
    event_text: str          # 事件方向指引
    summary: str             # 汇总段落（嵌入规划器 prompt）
    sticker_frequency: str   # 表情包频率："经常"|"偶尔"|"几乎不"
    sticker_style: str       # 表情包风格："强势"|"弱势"|"无偏向"|"喜欢"
    reply_context: str       # 精简描述（嵌入回复模块 prompt）
```

## 七个解码维度

见计划文件 `数值解码映射表 — 框架设计` 中的完整映射表。

## 降级策略

| 场景 | 降级 |
|------|------|
| 数值越界（好感<65等） | 抛 `InputRejected` |
| mood 列表为空 | 回退 `[{"label": "安心", "intensity": 2}]` |
| 未知 stop_reason | 按 normal 处理 + INFO 日志 |
| 未知情绪 label | 抛 `InputRejected` |
| 越界 intensity | 抛 `InputRejected` |

## 依赖

仅 `logging`（stdlib）。不调 LLM，不调 API。
