# 倍率变化器 - 模块规格 V1

## 职责

接收上一轮完整状态，计算本轮三个属性的变化倍率。所有属性联动关系的中央枢纽。
纯代码层计算，不调 LLM。

## 架构位置

```
上一轮 state → 倍率变化器 → 倍率系数
                                  ↓
StateUpdater → raw delta → × 倍率 → 最终 delta
```

## 输入

| 字段 | 说明 |
|------|------|
| `prev_moods` | 上一轮心情列表 `[{"label": str, "intensity": int}, ...]` |
| `prev_affection` | 上一轮好感度 0-100 |
| `prev_tension` | 上一轮紧张度 0-200 |
| `prev_initiative` | 上一轮主动性 0-100 |

## 输出

`{"affection": float, "tension": float, "initiative": float}` — 三个倍率系数

## 六条联动规则（加算叠加）

| # | 来源 → 下游 | 逻辑 |
|---|-----------|------|
| A | 心情 → 好感倍率 | 安心 +0.01×强度，开心 +0.03×强度，低落 -0.02×强度 |
| B | 心情 → 紧张倍率 | 安心 -0.02×强度，害羞 +0.03×强度，焦虑 +0.03×强度 |
| C | 心情 → 主动性倍率 | 开心 +0.01×强度，低落 -0.02×强度 |
| D | 好感 → 紧张倍率 | 低好感(0-40)→高紧张(+0.45~+0.35)，81-85 舒适区(0)，高好感(>86)→放松(-0.02~-0.20) |
| E | 紧张 → 好感倍率 | 紧张<30 不影响，紧张>90 大幅抑制好感(-0.30~-0.50) |
| F | 主动性 → 好感/紧张 | U 形曲线：以 50 为中心，偏离越远效果越强 |

详细数值见 [参考值.md](参考值.md)。

## 困惑缓冲

困惑存在时，所有倍率趋近 1.0——困惑越高，情绪反应越迟钝。
每级困惑缓冲 6%（社交困惑 5 → 缓冲 30%）。

## 钳位规则

| 倍率 | 钳位 |
|------|------|
| 好感倍率 | [0.5, 1.5] |
| 紧张倍率 | 不钳位（短期数值，允许剧烈波动） |
| 主动性倍率 | [0.5, 1.5] |

## 流程

```
审查（类型/范围校验）→ 计算（6条规则加算）→ 困惑缓冲 → 钳位 → 验证 → 输出
```

## 异常

- `InputRejected` — 输入类型/范围不合法
- `OutputInvalid` — 输出倍率超限（好感/主动性钳位兜底）
