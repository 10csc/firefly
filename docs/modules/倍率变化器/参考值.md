# 倍率变化器 —— 详细参考值表

> 计算方式：**加算叠加**。基线 = 1.0，各条规则的值叠加后钳位到 [0.5, 1.5]。
> 纵轴 = 来源属性（上一轮数据），横轴 = 下游目标倍率。
> 格式：【最小值, 最大值】表示该来源对下游的加算修正范围。

---

## 一、心情 → 倍率（6 种心情，强度 1-5 线性映射）

心情多情绪共存时各条独立加算，不互斥。

| 来源↓ / 下游→ | 好感度倍率修正 | 紧张度倍率修正 | 主动性倍率修正 |
|---|---|---|---|
| **安心** (1-5) | **+[0.01, 0.05]** | **-[0.02, 0.10]** | 0 |
| **开心** (1-5) | **+[0.02, 0.10]** | **-[0.03, 0.15]** | **+[0.01, 0.05]** |
| **低落** (1-5) | **-[0.02, 0.10]** | **+[0.02, 0.10]** | **-[0.02, 0.10]** |
| **焦虑** (1-5) | **-[0.01, 0.05]** | **+[0.03, 0.15]** | 0 |
| **害羞** (1-5) | 0 | **+[0.02, 0.10]** | **+[0.01, 0.05]** |
| **困惑** (1-5) | 0 | 0 | 0 |

> **公式**（直接乘强度）：
>
> - 安心: 好感 = `+0.01×强度`，紧张 = `-0.02×强度`
> - 开心: 好感 = `+0.03×强度`，紧张 = `-0.03×强度`，主动性 = `+0.01×强度`
> - 低落: 好感 = `-0.02×强度`，紧张 = `+0.02×强度`，主动性 = `-0.02×强度`
> - 焦虑: 好感 = `-0.01×强度`，紧张 = `+0.03×强度`
> - 害羞: 紧张 = `+0.03×强度`，主动性 = `+0.01×强度`
>
> 例：上一轮心情 = [安心:3, 害羞:2]
> - 好感倍率修正 = +0.03 (安心3) + 0 (害羞) = **+0.03**
> - 紧张倍率修正 = -0.06 (安心3) + 0.06 (害羞2) = **0.00**
> - 主动性倍率修正 = 0 (安心) + 0.02 (害羞2) = **+0.02**

## 二、好感度 → 紧张倍率（双向联动之 好感→紧张）

低好感 → 社交紧张（陌生感），高好感 → 放松舒适。好感增长过程中紧张倍率逐渐下降。

| 好感度当前值 | 紧张度倍率修正 | 区间公式 |
|---|---|---|
| 0 ~ 40 | **+[0.45, 0.35]** | `0.45 - 好感 × 0.0025` |
| 41 ~ 70 | **+[0.35, 0.25]** | `0.49 - 好感 × 0.00345` |
| 71 ~ 80 | **+[0.25, 0.10]** | `1.44 - 好感 × 0.0167` |
| 81 ~ 85 | **0** | 舒适区，不增不减 |
| 86 ~ 100 | **-[0.02, 0.20]** | `1.09 - 好感 × 0.0129` |

> 例：好感 = 85 → 处于 81-85 区间 → **0**
> 例：好感 = 92 → 处于 86-100 → `1.09 - 92×0.0129` ≈ **-0.10**

---

## 三、紧张度 → 好感倍率（双向联动之 紧张→好感）

高紧张 → 心生慌乱 → 好感难以自然表达。极度紧张时好感上升被大幅抑制。

| 紧张度当前值 | 好感度倍率修正 | 区间公式 |
|---|---|---|
| 0 ~ 30 | **0** | 放松，不影响 |
| 31 ~ 60 | **-[0.02, 0.05]** | `-(0.011 + 紧张 × 0.00103)` |
| 61 ~ 80 | **-[0.05, 0.20]** | `-(紧张 × 0.00789 - 0.431)` |
| 81 ~ 90 | **-[0.20, 0.30]** | `-(紧张 × 0.0111 - 0.699)` |
| 91 ~ 100 | **-[0.30, 0.50]** | `-(紧张 × 0.0222 - 1.722)` |

> 例：紧张 = 45 → 处于 31-60 → `-(0.011 + 45×0.00103)` ≈ **-0.03**
> 例：紧张 = 95 → 处于 91-100 → `-(95×0.0222 - 1.722)` ≈ **-0.39**

---

## 四、主动性 → 好感倍率（单向）

U 形曲线——以 50 为基准，两边偏离都为正修正。骑士和公主各有加分，卡在中庸最无趣。偏离越远修正越大。

| 主动性当前值 | 好感度倍率修正 |
|---|---|
| 0 ~ 30 | **+[0.04, 0.10]** |
| 31 ~ 50 | **+[0.02, 0.04]** |
| 51 ~ 70 | **+[0.02, 0.06]** |
| 71 ~ 100 | **+[0.06, 0.12]** |

> **公式**（以 50 为对称轴的 V 形）：
> - ini ≤ 50：`0.02 + (50 - ini) × 0.0016`
> - ini ≥ 50：`0.02 + (ini - 50) × 0.002`
>
> 验证：ini=0 → 0.10，ini=30 → 0.052，ini=50 → 0.02，ini=70 → 0.06，ini=100 → 0.12

---

## 五、主动性 → 紧张倍率（单向）

U 形曲线——以 50 为基准，两边偏离都降低紧张。有风格比没风格从容。偏离越远降紧张越多。

| 主动性当前值 | 紧张度倍率修正 |
|---|---|
| 0 ~ 30 | **-[0.04, 0.12]** |
| 31 ~ 50 | **-[0.02, 0.04]** |
| 51 ~ 70 | **-[0.02, 0.06]** |
| 71 ~ 100 | **-[0.06, 0.14]** |

> **公式**（以 50 为对称轴的倒 V 形）：
> - ini ≤ 50：`-(0.02 + (50 - ini) × 0.002)`
> - ini ≥ 50：`-(0.02 + (ini - 50) × 0.0024)`
>
> 验证：ini=0 → -0.12，ini=30 → -0.06，ini=50 → -0.02，ini=70 → -0.068，ini=100 → -0.14

## 计算示例

上轮状态：`好感=85, 紧张=20, 主动性=65, 心情=[安心:3, 害羞:2]`

```
好感倍率 = 1.0
  + 0.03    (安心:3, 0.01×3)
  + 0        (紧张20 < 30, 不触发)
  + 0.05    (主动性65 ≥ 50: 0.02 + (65-50)×0.002 = 0.05)
  ─────────────────
  = 1.08

紧张倍率 = 1.0
  - 0.06    (安心:3, -0.02×3)
  + 0.06    (害羞:2, 0.03×2)
  + 0        (好感85, 81-85舒适区)
  - 0.056   (主动性65 ≥ 50: -(0.02 + (65-50)×0.0024) ≈ -0.056)
  ─────────────────
  = 1.0 - 0.06 + 0.06 + 0 - 0.056 = 0.944

主动性倍率 = 1.0
  + 0        (安心)
  + 0.02     (害羞:2, 0.01×2)
  ─────────────────
  = 1.02
```

## 钳位规则

- 总倍率 = clamp(1.0 + 所有修正之和，**0.5**，**1.5**)
- 紧张度不设上限钳位——紧张是短期数值，后续有自动消退阶段，允许短期剧烈波动
- 加算顺序不影响结果
- 钳位在最后一步统一执行

## 设计要点总结

1. **开心 > 安心**：开心的修正幅度更大（×3），它是更"活跃"的正向情绪
2. **焦虑 ≠ 低落**：焦虑驱动紧张（+0.03/级），低落驱动好感下降（-0.02/级），各司其职
3. **焦虑不影响主动性**：焦虑时主动性冻结而非下降——她可能不知所措但不会退缩
4. **好感→紧张是非线性的**：陌生人阶段（0-40）社交紧张最高（+0.45），81-85 是舒适区（0），高好感反而放松（负修正）
5. **主动性 U 形**：有风格好过没风格，骑士和公主各有优势
6. **极度紧张锁好感**：紧张 >90 时好感上升被大幅抑制（-0.30~-0.50），需要先缓解紧张才能自然互动
