# 记忆管理器 — MemoryManager

## 职责

管理单会话记忆的持久化与整理。以"流萤休息/起床"为整理时机：
- **休息**：LLM 重写头部概括 + 追加尾部事实条目
- **起床**：加载头部到会话 session（`memory_head`），注入回复生成器的稳定层

## 文件

- 代码：[memory_manager.py](../../../app/modules/memory_manager.py)
- 测试：[test_memory_manager.py](../../../tests/test_memory_manager.py)
- 数据：`app/data/memory.md` + `.memory_index`

## 数据结构

### memory.md 双段结构

```
# 核心记忆头部（休息时 LLM 重写）
<500-1000 字概括，整合旧头部 + 本轮新事件>

# 事实与任务（追加区）
## 承诺
- [日期] 内容（使用 DeepSeek 搜索查询）
## 偏好
- [日期] 内容
## 事件
- [日期] 内容
```

### RestResult

| 字段 | 类型 | 说明 |
|------|------|------|
| success | bool | 整理成功 |
| new_head | str | 新头部文本 |
| added_entries | list | 本轮新增的事实条目 |
| resolved_entries | list | 本轮已解决的条目 |
| integrated_turn | int | 整理到的对话轮次数 |
| error | str | 失败原因 |

## 接口

### MemoryManager

| 方法 | 参数 | 返回 | 说明 |
|------|------|------|------|
| `load_head()` | — | str | 加载头部概括 |
| `load_tail()` | — | str | 加载尾部事实 |
| `rest(full_history, current_turn_count)` | list, int | RestResult | 休息时整理记忆 |
| `wake()` | — | str | 起床时加载头部（抛 MemoryError 若中断） |

## 流程

### rest 流程

1. 审查输入合法性
2. 读旧 memory.md（head + tail）
3. 读 `.memory_index` 上次整理到的轮次
4. 切片本轮新对话 → LLM 整理 →
   - 新头部（整合旧头部 + 新事件）
   - 已解决条目标记
   - 新事实条目（承诺/偏好/事件）
5. 原子落盘（tmp → replace）
6. 更新 index

### 中断检测

- `.memory_index` 存在但 `memory.md` 不存在 → 上次休息被中断
- `wake()` 抛 `MemoryError` → 前端显示起床遮罩提示用户刷新

## 上下文缓存设计

记忆头部注入回复生成器的**会话稳定层**（`_REPLY_MEMORY_PROMPT`），会话内不变：
- 跨会话：稳定层字节级不变 → DeepSeek 前缀缓存命中
- 会话内：记忆头部 session-stable → 同一 session 所有轮次命中缓存
