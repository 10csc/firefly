## 方法论要点（对角色设计有用）

1. **三维正交拆分角色**：把行为拆成互不重叠的三个维度，每维取离散取值：
   - 认知取向（高层思维）：sequential / divergent
   - 交互策略（中层偏好）：click / core_function / input
   - 习惯（底层执行）：valid_short / valid_long / invalid
   - 角色 = 一个维度取值元组 `<m, s, h>`，结构清晰、可组合、可系统化枚举

2. **从真实语料统计提炼，不拍脑袋**：标注 1500 条真实行为轨迹 → 统计各组合出现频率 → 只保留频率 >1% 的组合（18 种组合选出 9 种，覆盖 95.40% 的真实行为）。
   - 这就是 CLAUDE.md"第一层：真实世界是什么样"的落地做法：先用数据回答"人到底怎么表现"，再抽象成规则。
   - 频率阈值保证"代表性"而非"想当然"；覆盖率高保证不丢主流行为。

3. **配套验证**：同角色多次运行轨迹相似度高（自洽）、不同角色明显可分（有区分度）、真人盲评对齐度高（可识别）。

## 对火萤的潜在应用

- 若给流萤设计"情绪/状态"多维模型，可仿照：先收集真实对话/反馈语料 → 统计 → 频率门槛选代表性组合 → 元组化定义，而不是直接拍性格描述。
- 设计角色变化维度时（如 表达克制度 × 话题倾向 × 回应习惯），正交拆分的思路能避免维度间纠缠、难以调试的问题。
