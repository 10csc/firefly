# 信念-行为一致性：LLM 角色扮演 agent 说的≠做的

> 来源：Do Role-Playing Agents Practice What They Preach? Belief-Behavior Consistency in LLM-Based Simulations of Human Trust
> arXiv:2507.02197，COLM 2025 审稿中，UIUC + 佛罗里达大学 + CAMEL-AI（Guohao Li）
> PDF 暂存于 `C:\Users\FANGL\AppData\Local\Temp\opencode\belief_behavior.pdf`
> 可信度中上：团队强、实验严谨、prompt 全公开可复现；未正式发表、单场景（Trust Game）、N=50 personas。

## 核心结论

LLM 角色扮演 agent 的"设定/声称信念"与"实际行为"存在系统性不一致，群体与个体层面皆有。现有评估都是事后（post-hoc），应改为**部署前用信念 elicitation 做诊断**。

## 实验设计（方法论可复用）

- 测试床：Trust Game（信任博弈），persona 库 GENAGENTS + 大五人格增强
- 模型：Llama3.1-8B/70B、Gemma2-27B
- 群体层面：elicitation 3 策略（无上下文排名 / 带游戏上下文排名 / 直接预测金额）vs 实际仿真行为；指标 Spearman ρ + ANOVA η² 效应量差
- 个体层面：ReAct 多轮，每轮先预测再行动，MAE 衡量
- 控制：self-conditioning（注入自己的信念）、imposed priors（强加研究者先验）、金额消融

## 关键发现

1. 给任务上下文不提升一致性（context 无用，反直觉）
2. 直接预测行为→排名准但高估效应量；问抽象构念→效应量准
3. self-conditioning 模型差异极大：Llama3.1 提升（0.40→1.00），Gemma2-27B 崩溃（→<0.01，完全无响应）
4. **强加先验普遍破坏一致性**（弱扰动就 0.50→0.30）——in-context 提示无法覆盖模型先验，可控制性差
5. 预测越远越不准（MAE 随回合单调上升）

## 对火萤的落地要点

1. **人设卡写的 ≠ 实际做的**：上线前做"信念-行为一致性测试"（问流萤会怎么做 vs 实测对比）——场景真实化阶段缺失的一环
2. self-conditioning 思路可用但需实测：DeepSeek V4 是否响应设定注入，不可想当然
3. 不要指望 prompt 强行扭转模型先验（imposed priors 不可靠）；必要时用更强的机制
4. 角色一致性靠记忆（已发生的事）而非自我预测（未来行为）——现有记忆机制方向正确
5. 双层度量（排名相关+效应量 / MAE）可复用为"流萤像不像流萤"的量化评测
