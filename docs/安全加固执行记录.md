# 安全加固执行记录

> 背景：DSH 手机远程访问链路（手机 → 服务器 → PC）安全评估与加固。
> 威胁模型：拿到 `dsh_mobile` 私钥（APK 拆包）→ 原可 root 登服务器 → 服务器全丢 + 经 9090 指挥开发机。
> 日期：2026-08-14（当日完成阶段一）

## 链路现状（加固后）

```
手机 WebView → JSch -L 9090（dsh-tunnel 受限账号）→ 服务器 127.0.0.1:9090
             → PC 反向隧道（ssh -R，root 主 key）→ PC DSH 3080
管理后台 8766：仅本机 + 管理令牌（X-Admin-Token）双因子
```

## 已完成（全部验证通过）

### 1. 受限账号 dsh-tunnel（替代 root 登入）
- `useradd -m -s /usr/sbin/nologin dsh-tunnel`，无 sudo
- authorized_keys：`no-pty,no-agent-forwarding,no-X11-forwarding,no-user-rc,command="/bin/false"`
- 验证：`-L` 端口转发通（HTTP 200）；shell 被拒（exit 1）

### 2. 清理危险文件
- `/root/.ssh/firefly_root_pass.txt`（明文 root 密码）→ 移入 `/root/harden-backup/`
- `/root/.ssh/authorized_keys.bak_firefly` → 移入 `/root/harden-backup/`

### 3. 8766 管理后台加令牌（双因子）
- 服务器生成 `/opt/firefly/.admin_token`（48 hex，owner www-data，600）→ 副本在本地 `_harden/admin_token.txt`
- `server_app.py`：`ADMIN_TOKEN` 启动加载 + `AdminHandler._authed()`（127.0.0.1 + hmac 令牌，fail closed）
- `admin.html`：弹窗输入令牌 → localStorage 记忆 → 所有请求带 `X-Admin-Token` 头
- 验证：无令牌 403 / 有令牌 200；公网 8787 主服务 health/login 正常
- 服务器旧文件备份在 `/root/harden-backup/`（server_app.py.bak / admin.html.bak）

### 4. sshd 加固
- `X11Forwarding yes → no`，reload（未断连接）
- 既有防护确认：PasswordAuthentication no、fail2ban、firefly 服务 www-data 运行、9090 仅 127.0.0.1

### 5. 手机端 USER root → dsh-tunnel
- `MainActivity.kt` 已改，APK 重打包中

### 6. ✅ 已收尾：从 root 的 authorized_keys 删除 dsh-mobile 行
