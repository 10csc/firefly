## 产品

- Firefly 是以流萤为主要角色、同时允许用户制作和使用其他角色包的独立角色扮演应用。
- 本地版可独立运行在 Windows 和 Android；手机端不需要电脑提供后端。
- 服务器提供账号、同步、下载、更新、热更新、公告，以及登录后的角色卡共创平台。
- 服务器不提供 App 本体前端。App 前端与平台前端是两套产物，边界见 [角色卡平台](概念/角色卡平台.md)。

## 能力

- 对话流水线：检索 → 分析 → 回复 → 组织器 → 写历史。
- 角色包：`preset.json`、角色文本、知识库、提示词覆盖、开场、表情与图片。
- 消息能力：文本、图片、表情、旁白、引用、收藏、主动消息和语音附件。
- 数据能力：本地持久化、备份、快照、跨设备同步、清理与撤回墓碑。
- 平台能力：广场、搜索筛选、制卡、草稿、AI 审核、发布、改编、举报与治理。
- 更新能力：RSA 签名的累积热更新，以及签名公告通道。

## 活动边界

- 未经用户明确放行，不 bump 版本、不构建发行包、不推送、不部署、不发布热更新。
- `server/` 不进公开主仓，服务器源码同步到受控私有仓库；生产更新仍按清单单文件部署并回读核验。
- 热更新只修 bug，不发布新功能；底座变化必须发整包并使旧补丁线失效。
- 平台页与 App 前端分离；平台前端不由 App 热更新覆盖。
- 旧测试与旧审计报告已归档，不再作为当前通过证据。当前验证入口见 [测试基线](参考/测试基线.md)。
