# 安装器静默行为与用户自测说明（W4）

> 依据：`package/firefly.iss`（**只读**，本轮未改此文件）。
> 边界：**本机未做任何安装/卸载验证**（收口硬闸门 #2）。本文只做**代码层查明**，
> 再给**用户在自己 Windows 机**上的安全自测步骤。判定由用户在自测中给出。

## 一、iss 相关行（行号 + 原文）

`package/firefly.iss` 当前工作区文件，相关行逐字如下（行号为该文件行号）：

| 行 | 原文 |
|---|---|
| 20 | `CloseApplications=yes` |
| 21 | `CloseApplicationsFilter=firefly.exe` |
| 55 | `[Run]` |
| 56 | `Filename: "{app}\firefly.exe"; Description: "启动 Firefly"; Flags: nowait postinstall skipifsilent` |

- **`[Run]` 段全部内容 = 第 55、56 两行**（第 57 行起无其它条目，该段即结束）。
- **`skipifsilent`**：在第 56 行 `Flags: nowait postinstall skipifsilent` 中，**带**。
- **`CloseApplications`**：第 20 行 = `yes`；**`CloseApplicationsFilter`**：第 21 行 = `firefly.exe`。
- **`RestartApplications`**：全文件**未出现**（`grep -c 'RestartApplications' package/firefly.iss` = **0**）。
  - 事实：Inno Setup 官方文档规定 `RestartApplications` 的**默认值 = `yes`**。
  - ⚠️ 标注：以上是**文档默认值、本机未验证**（本文未跑安装器，闸门 #2）。

## 二、代码层判定（按 Inno 官方语义）

Inno Setup 文档（`[Run] & [UninstallRun] sections`）对 `skipifsilent` 的定义逐字为：

> "Valid only in a `[Run]` section. Instructs Setup to skip this entry if Setup is running (very) silent."

⇒ **在 `/SILENT` 或 `/VERYSILENT` 下，第 56 行的 `[Run]` 条目应被跳过**，
即"静默安装后由 `[Run]` 主动拉起 `firefly.exe`"这条**在文档语义上不成立**。

另据同源文档（`[Setup]: CloseApplications` / `RestartApplications`，此处 `CloseApplications=yes`）：

> "If set to `yes` or `force` and Setup is running silently, Setup will always close and restart such applications..."

> "When set to `yes` and `CloseApplications` is also set to `yes` or `force`, Setup restarts the closed applications after the installation has completed."

⇒ 若**安装时 `firefly.exe` 已在运行**，"关闭→重启"是**理论上另一条**能拉起 app 的路径
（前提：该进程正在运行、且 app 使用 `RegisterApplicationRestart`）。

### 矛盾如实说明（不编造因果）

上一轮**两次实测**（真实 AppId 一次、一次性 AppId 一次）静默安装后，`{app}` 下都出现了
**运行期目录** `hotupdate/ notice/ logs/ user_data/`，且 `logs/firefly.log` 时间戳 = 安装结束时刻
⇒ 现象上 **app 很可能被拉起过**。

但**触发路径未能确定**，三个候选**都没有隔离证据**可判定是哪一个：

1. `[Run]` 条目本身（按文档应被 `skipifsilent` 跳过 ⇒ 与现象矛盾）；
2. `CloseApplications=yes` + `RestartApplications` 默认 `yes` 的"关闭后重启"
   （需要安装时 app 正在运行，当时是否在运行**未记录**）；
3. 沙箱环境对安装落点/进程的改写 —— `docs/错误总结.md` #32 已证本沙箱会改写安装落点
   （`/DIR` 被忽略、末段恒为 `AppName`），是否也影响进程行为**未验证**。

**结论**：按文档，`[Run]` 在静默下应被跳过；**实测现象与文档不符**，
但**是 `[Run]`、是 Close/Restart、还是沙箱，本轮无法确定** ⇒ **不下结论、不编因果**。
本机不复现（闸门 #2 禁止安装/卸载），故把判定交用户在自测中做（见 §三）。

## 三、给用户的 3 步自测（在**用户自己的 Windows 机**上）

> 安全前提：本步骤只测**一次性 AppId 的副本**。
> **绝不能用真实 AppId 的包在本机静默安装**（闸门 #2；#32 事故根因）。

### 第 1 步：先备份 `E:\Firefly`（必做，先于一切）

PowerShell（建议管理员）：

```powershell
Get-ChildItem -Path 'E:\Firefly' -Recurse -Force |
  Select-Object FullName, Length, LastWriteTime |
  Export-Csv -Path "$env:USERPROFILE\Desktop\Firefly_目录清单_$(Get-Date -f yyyyMMdd_HHmmss).csv" `
             -NoTypeInformation -Encoding UTF8
```

**为什么先备份**：上一轮（`docs/错误总结.md` #32）用真实 AppId 的包**原地覆盖**了 `E:\Firefly`，
而 **0.8.0 的二进制当时没有留字节**（只留了哈希）⇒ 事后**无法回滚**。
清单至少要能证明"哪些文件被动过"。
> 清单 ≠ 字节备份。要能真正回滚，还需按 `docs/部署与发布约定.md` §5 归档旧安装包**字节**
> （见 `05_发布检查单.md` §⑤）。

### 第 2 步：从 `package/firefly.iss` 生成"一次性 AppId"副本

复制 `package/firefly.iss` → 新文件（例：`firefly-selftest.iss`），**只改这 4 处**，
其余**逐字保持**，尤其第 56 行的 `Flags: nowait postinstall skipifsilent`（被验构造不许动）：

| 原行 | 原值 | 改成（示例） |
|---|---|---|
| 3 | `AppId={{F1E7A3C5-9B2D-4E6A-8F1C-3D5B7A9E0C41}` | 换一个**全新 GUID**（不能与真实 AppId 相同） |
| 4 | `AppName=Firefly` | `AppName=FireflyTest` |
| 11 | `OutputBaseFilename=firefly-setup` | `OutputBaseFilename=firefly-selftest` |
| 52–53 | `[Icons]` 名字 `Firefly` | `FireflyTest`（桌面 + 开始菜单名字一起换） |

用 Inno 编译器产出：`ISCC.exe firefly-selftest.iss` → `firefly-selftest.exe`。
> ⚠️ 本沙箱环境会把落点改写为 `E:\<AppName>`（#32 实测：真实包 → `E:\Firefly`、
> 一次性包 → `E:\FireflyTest`），**用户机上请自行核对实际落点**，
> 确认目标是 `E:\FireflyTest` 而不是 `E:\Firefly` 后**再**执行第 3 步。

### 第 3 步：静默安装并观察（观察点）

```powershell
# 先确认 firefly.exe 当前未运行（隔离候选 2 的前置条件）
tasklist | findstr /I firefly
# 跑一次性 AppId 的包（用你核对过的落点）
Start-Process -FilePath '.\firefly-selftest.exe' -ArgumentList '/VERYSILENT','/NORESTART' -Wait
```

安装结束后 **5 秒内**做三件事：

1. **看进程**：`tasklist | findstr /I firefly`（或任务管理器）⇒ 记录是否出现 `firefly.exe`。
   若出现 ⇒ 静默下确实被拉起，**与 `skipifsilent` 文档语义矛盾**，需继续查候选 2/3。
2. **看目录**：检查 `{app}\logs`、`{app}\hotupdate` 是否**被创建**。
   ⇒ 这两个目录**只有 app 真正运行过才会出现**，是"是否被拉起"的**客观判据**。
3. **看时间**：`dir "{app}\logs\firefly.log"` 的时间戳是否 ≈ 安装结束时刻（#32 观察到的现象）。

> 用后清理：只卸载这一个一次性 AppId 的 `FireflyTest`，**不要**碰 `E:\Firefly`。
