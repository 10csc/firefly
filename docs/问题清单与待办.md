## 二、首页修复方案（问题 1）

目标：首页是**覆盖层**，与聊天页 `#app` **同位置同尺寸**（PC 520px 居中 / 手机全宽），盖在对话页上层（z-index: 5，低于菜单 49/表情面板 55）。

```css
#home-view {
    position: fixed;
    top: 0; bottom: 0;
    left: 50%; transform: translateX(-50%);   /* 居中，与 #app 对齐 */
    width: 100%; max-width: 520px;            /* 手机全宽 / PC 520 居中 */
    z-index: 5;
    display: none; flex-direction: column;
    background: rgba(20,20,40,0.92);          /* 面板背景，不遮两侧 */
}
#home-view.show { display: flex; }
```

- 删除桌面 @media 里对 #home-view 的 `left/transform` 覆盖（base 已处理，避免重复/冲突）
- 现有文件：`app/static/style.css`（#home-view 段有两处：主段 + 桌面 @media 里的两处规则，需清理合并）
