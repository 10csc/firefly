## 二、项目背景速览（新会话上下文）

- 项目：流萤角色扮演 Agent（DeepSeek API + LLM 子代理检索 + 剧本系统）
- **双线版本**：
  - **本地版**（`app/`）：PC（PyInstaller）+ 安卓（Chaquopy），用户设备独立运行
  - **服务器版**（`server/`）：云服务器多用户，用户自带 API Key（存浏览器），数据按账号（user_id）隔离——见 docs/部署说明.md
- 仓库：本地 git（不要 push github！）；备份：`firefly_backup_*.bundle` + `firefly_keystore_backup_*/`（根目录，gitignore）
- 关键路径：
  - 本地版后端：`app/`（server.py/routes.py/orchestrator.py/modules/）
  - 服务器版：`server/`（server_app.py/frontend/，复用 app/modules + app/routes）
  - 前端：本地版 `app/static/`，服务器版 `server/frontend/`（**双份维护，改通用逻辑需同步**）
  - 知识库+剧本：`knowledge/`（剧本在 `knowledge/剧本/版本/`）
  - 安卓：`android/`（构建用 gradle-8.9，签名在 `android/keystore/`）
  - 安装器脚本：`package/firefly.iss`（Inno Setup）
- 测试：`tests/test_*.py` 独立脚本运行（`python tests/test_xxx.py`）
- 服务：本地 `python app/server.py` → http://localhost:8765；服务器版 `python server/server_app.py` → 0.0.0.0:8765
- 版本发布：GitHub Release（v0.6.0 已有 firefly-setup.exe + firefly.apk）——**发布到 github 的操作仅限用户明确要求时**
