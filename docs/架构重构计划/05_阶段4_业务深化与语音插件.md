### 任务 4.1：语音插件接入【需拍板：模型分发方式】
- 证据：`论文/流萤语音合成研究_GPT-SoVITS_V4_ONNX全链路.md`（ONNX 641M INT8，PC+安卓真机已验证）；版权约束：第三方整合包禁止售卖、原声归 mihoyo
- 拍板点（开工前必须确认）：
  1. 模型获取方式：用户手动导入 zip / 提供下载指引页（**不可随安装包分发**）；
  2. 是否只做 PC 本地版第一刀（安卓后续）；
  3. onnxruntime 依赖引入（零依赖铁律的唯一例外，需明示批准）
- 目标结构（拍板后执行）：
  1. `preset.json` 增 `capabilities.voice`（可选，宽进；老版本读到忽略）；
  2. 包槽位 `{mode}/character/voice/`（refs/ 参考音频 + voice.json 参数）；
  3. 新模块 `domain/voice/`：`has_voice(mode)` / `synthesize(text, mode, emotion) -> wav_path|None`；引擎懒加载，import 失败=功能关闭；
  4. `storage.REGISTRY` 注册三行：`voice_engine`（exclude）/`voice_refs`（metadata）/`voice_cache`（exclude+LRU 200MB/包）；
  5. 端点 `POST /tts {seq, mode}`：按 seq 取对话文本→合成→返回 wav；前端气泡播放按钮（仅 has_voice 包显示，点击才合成，不预生成）；
  6. 服务器版强制关闭（capabilities 在 FIREFLY_SERVER 下视为 false）；
  7. 首次启用 UI 展示来源与版权提示。
- 禁止：改对话流水线；把 wav 写进 conversation.jsonl；预合成
- 验收：无引擎/无模型/无槽位三种环境零报错降级；有引擎环境合成出可播 wav；全量测试绿
- 回滚：功能开关级关闭（capabilities.voice=false 即全关）
