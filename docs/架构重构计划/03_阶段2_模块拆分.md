# 阶段 2 · 模块拆分（纯移动，零行为变化）

> 目标：拆掉两个超大枢纽文件与若干重点文件，落实 core/domain/infra/api 分层。
> **铁律：本阶段只移动代码与 import，不改任何逻辑。** 每张子卡完成后必须全量测试 + oracle 绿。
> 预计 ~8 天。前置：阶段 0/1 完成。

## 拆分的通用手法（每张卡都遵守）
1. 新文件落位 → 旧文件改为 re-export 兼容层（`from core.paths import *` 式，显式列出名字，不用 `*`）；
2. 逐模块改 import（一批改完立刻跑全量测试）；
3. 全部消费方改完后，兼容层保留一个阶段，下阶段再删；
4. **PyInstaller 约束**：`routes.py:26` 注释要求路由相关 import 必须顶部静态（hiddenimports 靠静态分析），禁止改成函数内 lazy import；
5. 每卡 = 一个 commit，commit message 格式：`refactor: 阶段2.X <名称>（纯移动）`。
