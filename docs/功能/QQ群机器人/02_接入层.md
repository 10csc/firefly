# 接入层

代码：`server/qqbot/`，入口 `server/qqbot_boot.py`。

## 为什么用 HTTP 而不是 WebSocket

`server/` 是**纯标准库**（无 Flask/FastAPI、无 requirements.txt，venv 里只有 `requests`）。
标准库没有 WebSocket 客户端，自己实现握手与帧编解码要百余行且增加出错面。
而 OneBot v11 的「HTTP 上报」+「HTTP API」两个方向都是普通 HTTP，用 `urllib` 即可闭环——
零第三方依赖，正好落在项目「禁止为一行代码引入一个库」的依赖铁律里。
一个群的消息量级下，每事件一次 HTTP 请求的开销可忽略。

## 链路

```text
QQ 服务器 ←→ NapCat（Node，约 150MB） ←→ qqbot 适配层（Python 标准库） ←→ handle_chat
   ↑                HTTP POST 上报 / HTTP API 调用              ↓
   └──────────────────── send_group_msg ────────────────────────┘
```

## 模块划分

| 模块 | 职责 | 模块铁律位置 |
|---|---|---|
| `config.py` | 阈值单一来源，读环境变量并夹边界 | 审查输入 |
| `guard.py` | 准入 → 配额 → 内容 三道闸 | 审查约束 |
| `onebot.py` | OneBot v11 API 客户端、消息解析 | 处理 + 验证输出 |
| `session.py` | 群级主线 + 用户级记忆 | 状态 |
| `handler.py` | 主链编排 | 处理 + 验证输出 |
| `server.py` | 事件接收（只监听回环） | 接收输入 |

**为什么是包而不是扁平模块**：模块名 `config` / `server` / `session` 太通用，
`app/server.py` 已存在，扁平导入会撞名。用包 + 相对导入把命名空间隔离在 `qqbot.` 之下。

## 端口与监听（不可写反）

生产公网只开 `22 / 443 / 8787`，`8765 / 8766` 仅回环。群机器人**必须**遵守：

- 适配层监听 `127.0.0.1:8790`（默认，可配；非回环地址启动自检直接拒绝）。
- **NapCat 自己的端口同样只绑回环**（WebUI 6099、WebSocket 3000/3001）。
  NapCat 的 WebUI 若暴露公网等于把机器人账号的扫码登录入口开放给全网。

## 上报签名

配了 `FIREFLY_QQBOT_SECRET` 就强制校验 `X-Signature: sha1=<hex>`（HMAC-SHA1），
不匹配直接 403。未配置时打印一次告警并放行（依赖回环监听这一前提）。

## 消息收发要点

- **发送一律 `auto_escape=True`**。否则用户消息里的 `[CQ:at,qq=...]` 会被当指令解析，
  这是一条真实的注入面。测试里用真实 HTTP 捕获请求体做了断言。
- **单条上限 1500 字**，超出截断后再发。
- **`retcode != 0` 一律视为失败**并返回原因码，不允许"发出去了就算成功"。
- 事件上报先回 200 再异步处理：LLM 耗时几秒，不能拖满 NapCat 的上报超时（默认 5s）。
  同一群用会话锁串行，保证上下文不乱序。

## 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `FIREFLY_QQBOT_GROUPS` | `1097936258` | 群白名单，逗号分隔；**空 = 拒绝所有** |
| `FIREFLY_QQBOT_DAILY_TURNS` | `50` | 群每日总轮次 |
| `FIREFLY_QQBOT_USER_DAILY` | `15` | 单用户每日轮次 |
| `FIREFLY_QQBOT_USER_PER_MIN` | `3` | 单用户每分钟 |
| `FIREFLY_QQBOT_MAX_INPUT` | `500` | 单条输入上限（超出截断） |
| `FIREFLY_QQBOT_MAX_REPLY` | `3` | 一轮最多回几条 |

上下文窗口**不在这里配**：沿用项目既有的 `memory_window_turns`（100 轮触发整理）与
`memory_keep_turns`（整理后保留 30 轮），与单人版同一套。会话层不得自行裁剪，
理由见 [04_会话模型](04_会话模型.md)。
| `FIREFLY_QQBOT_ONEBOT_URL` | `http://127.0.0.1:3000` | NapCat HTTP 地址 |
| `FIREFLY_QQBOT_TOKEN` | 空 | OneBot API 鉴权 |
| `FIREFLY_QQBOT_SECRET` | 空 | 上报签名密钥 |
| `FIREFLY_QQBOT_DATA_DIR` | `/opt/firefly/qqbot_data` | 独立数据根 |
| `DEEPSEEK_API_KEY` | 无默认 | **群机器人专用 Key**，缺失则拒绝启动 |
