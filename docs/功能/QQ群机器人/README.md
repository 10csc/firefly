# QQ 群机器人

让 Firefly 的角色扮演流水线接入 QQ 群，以「插件/渠道适配层」形式存在，不改动主流水线。

## 一句话定位

`server/qqbot/` 是一个**渠道适配层**：把 QQ 群消息翻译成 `handle_chat` 的输入，
再把输出翻译成群消息。流水线本身（检索 → 分析 → 回复 → 组织器）一个字都没改。
