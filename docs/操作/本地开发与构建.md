# 本地开发与构建

本页覆盖本地运行、活动测试、PC 构建和 Android 构建。发布边界见
[发布规则](../参考/发布规则.md)，当前测试范围见 [测试基线](../参考/测试基线.md)。

## 前提

- Python 3.10+；运行时第三方依赖只有 `requests>=2.28`。
- PC 构建使用 PyInstaller；安装器使用 Inno Setup。
- Android 构建使用 JDK 17、Android SDK 和项目自带 Gradle 配置。
- 以下 Windows 路径是当前开发机示例，换机器时先重新探测，不要把绝对路径当项目合同。

本机已验证位置：

| 工具 | 示例位置 |
|---|---|
| Python | `D:\python_all\Python312\python.exe` |
| JDK 17 | `D:\Java` |
| Android SDK | `F:\CodeFile\firefly\android\sdk` |
| Gradle 缓存 | `D:\Android\.gradle` |
| Inno Setup | `C:\Program Files\Inno Setup 7\ISCC.exe` |
| adb | `F:\Android_SDKset\platform-tools\adb.exe` |

## 本地运行

```powershell
Set-Location F:\CodeFile\firefly
python -m pip install -r requirements.txt
$env:PYTHONUTF8 = "1"
$env:PYTHONIOENCODING = "utf-8"
Set-Location app
python server.py
```

服务默认只监听本机；打开 `http://127.0.0.1:8765`。首次使用在设置页填写 API Key。
运行数据写入 `user_data/`，不得把真实用户目录提交或打进发行包。

## 当前活动测试

活动目录包含同步四套、hot5 发布链、G1 回滚测试、共享 harness 和 JS 合约。
`sync_real_harness.py` 是共享 harness，不单独执行：

```powershell
Set-Location F:\CodeFile\firefly
$env:PYTHONUTF8 = "1"
$env:PYTHONIOENCODING = "utf-8"
python -B tests\test_sync_http_e2e.py
python -B tests\test_sync_concurrency.py
python -B tests\test_sync_crash_recovery.py
python -B tests\test_sync_spec_guard.py
python -B tests\test_hot5_release_pipeline.py
python -B tests\test_deploy_rollback.py
python tools\check_docs_execution.py
python tools\check_docs_execution.py --self-test
```

每份脚本的退出码和 PASS/FAIL 都要记录。旧测试、手工探针和历史报告已归档，不再通过
`Get-ChildItem tests\test_*.py` 批量运行，也不把它们的数量当作覆盖率。
`test_hot5_release_pipeline.py` 验证既有 hot5 产物，不表示当前源码已发布；
`test_deploy_rollback.py` 只在临时沙箱读写。

## 常用门禁

```powershell
$env:PYTHONUTF8 = "1"
python tools\check_version.py

python tools\check_hotupdate.py --all

python tools\check_docs_execution.py
python tools\check_docs_execution.py --self-test
```

前端同步的当前语义是：

- `app/static/` 是 App 唯一前端源，进入 Android 打包 assets。
- `server/frontend/` 只保存登录页、角色卡平台白名单和平台 bundle，不接收 App 前端镜像。
- 平台 bundle 用 `python tools/build_frontend_bundle.py --platform` 生成。
- `server/frontend/` 每个顶层文件都必须在 `tools/sync_frontends.py` 显式分类。

## 构建 PC

```powershell
Set-Location F:\CodeFile\firefly
$env:PYTHONUTF8 = "1"
python -m PyInstaller firefly.spec --noconfirm
Remove-Item -Recurse -Force dist\firefly\user_data -ErrorAction SilentlyContinue
& 'C:\Program Files\Inno Setup 7\ISCC.exe' package\firefly.iss
```

产物：

- `dist\firefly\firefly.exe`
- `package\firefly-setup.exe`

构建后至少启动一次，确认 `/config` 可用。发行前再次确认 `dist/firefly/user_data` 不存在。

## 构建 Android

```powershell
$env:JAVA_HOME = "D:\Java"
$env:PATH = "D:\python_all\Python312;$env:PATH"
$env:ANDROID_HOME = "F:\CodeFile\firefly\android\sdk"
$env:PYTHONUTF8 = "1"
$gradleBat = Get-ChildItem 'D:\Android\.gradle\wrapper\dists' -Recurse -Filter 'gradle.bat' |
  Select-Object -First 1 -ExpandProperty FullName
& $gradleBat -p F:\CodeFile\firefly\android assembleRelease --no-daemon
Copy-Item F:\CodeFile\firefly\android\app\build\outputs\apk\release\app-release.apk `
  F:\CodeFile\firefly\android\firefly.apk -Force
```

前端有改动时使用 clean build，避免 Gradle `Sync` 的旧中间产物混入 APK。安装验证：

```powershell
& 'F:\Android_SDKset\platform-tools\adb.exe' -s <设备序列号> install -r `
  F:\CodeFile\firefly\android\firefly.apk
```

## 包内验收

上传或安装给用户前必须核对包内真实内容，而不是只看构建成功：

```powershell
python tools\check_apk_manifest.py android/firefly.apk allowBackup usesCleartextTraffic
python tools\check_apk_frontend.py
python tools\check_backend_sync.py --check
```

任何新增资产都必须同时登记到同步工具和 Gradle `Sync` 输入。放进 `Sync` 输出目录的文件会在下一次构建时消失。

## 禁止事项

- 不删除 SDK、Gradle、build 或 dist 缓存来“修复”构建。
- 不提交密钥、keystore 内容、真实 `user_data`、数据库或备份。
- 未经授权不 bump 版本、不创建 Release、不推送、不部署、不发布热更新。
- 不把旧测试恢复成默认回归集；需要覆盖新风险时重新设计独立 oracle。
