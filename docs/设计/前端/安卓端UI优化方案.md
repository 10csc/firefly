# 安卓端 UI 优化方案

> 状态：待评审（2026-08-17）。基于真机实测（adb 截图，1080×2376）+ 源码走读。
> **用户规则：本方案中每条标注「建议改」或「保持现状」。标「保持现状」的是用户特意设计、
> 不动的；标「建议改」的也需用户逐条勾选后才实施。**

## 6. 实施顺序建议

1. 先做的三件（高收益低风险）：5.2 基线测量 → 2.1 主色调统一 → 4.1 首页层级。
2. 中批：3.2/3.3/3.4 交互动画、4.5 抽屉、2.2 气泡。
3. 视情况：5.4 图片压缩（涉及打包流程，单独评估）。
4. 所有改动完成后：跑 `python tools/sync_frontends.py --check` 校验三端一致，再 adb 截图对比本方案 §1 的基线图。
