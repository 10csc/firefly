## 0. 硬规则（逐条写"建议文本"时必须遵守，Lead 逐条抽查）

1. **不许**出现堆栈 / 文件名 / 内部术语 / **裸英文错误码**（如 `HTTPError 429`、`KeyError`、`{act!r}`）。
2. 短提示 **≤1 行**；需要长解释的**折叠**到可展开处，不刷屏。
3. **同一概念同一措辞**：同类错误全仓用同一句，不许一处一个说法。
4. 语气**温柔克制、不甩锅、不吓人**。
5. **上游的问题不许写成"你的操作有误"**；**用户的错不许写成"网络问题"**；每条都给**可执行的下一步**（能重试的说重试与间隔；要改配置的说清改哪个）。
