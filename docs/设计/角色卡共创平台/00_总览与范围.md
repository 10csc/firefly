## 零、架构约束（2026-10-01 用户纠正，硬性）

> **服务器只做后台，不对外提供 App 前端。**
> 服务器只提供三样：① **客户端 API**（账号/同步/下载/更新/热更/公告）；② **角色卡平台**
> （登录后用：广场 / 制卡 / 我的卡 / 治理台，见 [08 平台边界](08_平台边界-平台不等于App.md)）；
> ③ **登录页**。**不得**提供 `/index.html`、`/js/bundle.js`、`/js/panels/*`、`/style.css`、`/pc.css`
> —— 那些是本地版 App 的东西，服务端闸门把它们挡成 **302（壳）/ 404（资源）**。

自查（只读、可重跑）：

```bash
python tools/check_server_surface.py --strict-platform   # 服务端对外面矩阵：App 前端不可达 + 平台/API 可达
python tools/check_server_contract.py                    # 客户端引用面 ⊆ 服务器注册表 + 无 App 页引用
python tools/sync_frontends.py --check                   # server 侧只准有平台文件（不再镜像 app/static）
```

机制防线（**别再搬 App 上服务器**）：`tools/sync_frontends.py` 对 server 侧只做**平台白名单自检**，
不再从 `app/static` 镜像任何文件；`app/static → 安卓 assets` 的同步保持不变（App 本地模式不受影响）。

## 二、已确认的产品决策（用户 2026-10-01 拍板）

1. **广场完全登录可见**（未登录不可浏览任何卡片内容）。
2. **制卡走站内结构化表单**（不做 zip 上传）。
3. **发布审核 = AI 审核**：用户填写**自己的** DeepSeek API Key，**服务器只接受 `sk` 格式**，其余由后端代码驱动；后端用该 Key 调用模型审查卡片合规性；**审完立即删除 Key，不保留任何记录**。叠加注册登录前置门槛。
4. **客户端两端都做**（本地版 + 服务器版共用同一套前端与安装逻辑）。要求严谨、美观。
5. **传输安全走 A 路线**（2026-10-01 追加拍板）：Let's Encrypt **纯 IP 证书**（免费、无需域名、无需备案标识）
   + Python 标准库 TLS 终止 + **双端口灰度**（443 TLS / 8787 明文并存），兼容到旧客户端全部升级完为止。
   详见 [05 安全与登录](05_安全与登录.md)。用户要求：**安全无小事**，服务器变更随 0.9.1 整包发版。
6. **服务器为固定带宽 ≈0.3MB/s（3Mbps）**，流量不计费 → 目标从「防花钱」转为「**防抢占 + 防滥用**」。

## 三、关键事实基线（全部有据，禁止再凭印象推翻）

- **版本号：仓库当前是 0.9.0**（`app/core/config.py:93`、`app/static/js/update.js:18`、`server/frontend/js/update.js:18`、`server/version.json:2`、`android/app/build.gradle.kts:92-93`、`package/firefly.iss:5`）。`0.9.1` 仅存在于文档/注释（`docs/交接说明.md:20`、`docs/维护与开发双轨.md:16`）。本功能发版时 7 处统一升 0.9.1（`tools/check_version.py:38-49`）。
- **角色卡 = `character/` 子树**（`app/routes_pack.py:9-13` 有明文边界）；用户数据在 `{mode}/data|journal|images/`（`app/modules/storage.py:90-137`）。**现有导出/快照按包 id 打包整个 `user_data/{id}/`，卡与数据混装，没有"只装卡"的产物**（`app/core/presets.py:137-147` + `app/routes_snapshot.py:54-70`）。
- **服务器版当前是零自建包**：`app/api/pack_lifecycle.py:58-59` `_is_server()` 直接拒绝建包；`app/core/presets.py:63` 服务器版不扫用户自建包；`app/routes_pack.py:288` 注释「服务器版不做自定义整包」。→ **需求 3 在服务器模式下必须动这条边界**（见开放决策 D1）。
- 包 id 唯一权威正则 `_PRESET_ID_RE`（`app/core/preset_parse.py:27`）；目录解析**必须**用 `cfg.pack_root(pid)`（`app/core/paths.py:143-150`），`mode_root` 对未注册 id 会**静默回退默认包**。
- 可直接复用的安全设施：`_zip_safe_entries`（`app/infra/sync/restore.py:63`）、体积上限（`:42-48`，单文件 20MB/总 100MB/zip 60MB）、`_swap_dir_into_place` 原子换入+回滚（`:135-165`）、`atomic_write_bytes`（`app/modules/storage.py:41-50`）、`parse_multipart(max_bytes=)`、请求体上限与 CORS（`app/shared_http.py:69-87`）。
- **服务器实况（2026-10-01 只读实测）**：2 核 / 1612MB 内存 / **无 swap** / 磁盘 33G 可用 / load≈0；公网仅开 22 + 8787；`firefly-server`(8765,www-data,venv) 与 `firefly-downloads`(8787,www-data) 两单元；cron 仅每日 3:00 备份 + 每分钟 `attack_watch.sh`；**tc 与 sar 可用，无 nginx、无 vnstat**；eth0 累计 RX 6.0GB / TX 18.5GB，开机 50 天 → 出向均值 ≈370MB/日。
- **流量控制现状**：网关 `RATE_PER_MIN=3000`（键=IP+token 指纹）、`MAX_THREADS=64`、大文件 `DL_SEM=2`（>5MB）、同 IP 最多 2 个下载、排队上限 600s、socket 空闲 120s；主服务 `MAX_THREADS=128` + 队列 128 → 503+Retry-After。**全仓没有任何带宽维度的限速，也没有流量计量；下载统计只记次数不记字节**（`server/download_lib.py:80-131`）。
- **没有 gzip/zstd/brotli**（全仓 Python 无 `Content-Encoding`）；唯一压缩是前端 Canvas 预压（`app/static/js/imgzip.js:8-9`，单边 ≤1024px 且 ≤300KB）。
- **热更新不能发新功能**（`docs/热更新规范.md:29`）→ 本功能必须走整包发版；**底座变了必须升版本号**（同文件 §5.4）。
- **门禁**：改 `app/` 或 `app/static/` 后 = 80 个 `tests/test_*.py` + `check_version.py` + `sync_frontends.py --check` + `build_frontend_bundle.py --check` + `check_backend_sync.py --check`（+ 发版时 `check_hotupdate.py`、`check_apk_manifest.py`）；前端三副本 = `app/static/` → `server/frontend/`、`android/.../assets/`。

## 五、角色卡归档格式（草案，详见 01）

`card.zip`（顶层单目录）：
```
manifest.json     # 卡元数据：id/name/char_name/user_name/presentation/desc/tagline/分类/标签/作者/版本/sha256
character/        # 只含角色卡子树：preset.json、core.md、identity.md、sms_samples.md、
                  # prompts/*.md、opening.json、assets/{avatar,cover}.{webp|jpg|png}
```
- 体积硬上限：**单附件 ≤300KB、整卡 ≤1.5MB**（服务器侧二次压缩 + 拒绝）。
- `manifest.json` 复用现有 `_pack_digest` 哈希口径（`app/infra/sync/manifest.py:34-42`）便于客户端校验。
- **不含** `data/`、`journal/`、`images/`、`memory/`（用户数据）。

## 九、风险与"不做"

> **发布冻结（用户 2026-10-01 明确指示）**：**先不要真的发布出去**。
> 本方案的所有产出（代码、文档、测试）**只落本地仓库**：不部署服务器、不传 Gitee/阿里云、
> 不打安装包、不热更、不 git push。对生产服务器只允许**只读**命令。
> 任何"发出去"的动作（部署/发版/上传）**必须先取得用户当轮明确放行**。

- 服务器 **1612MB 内存无 swap**：plaza 必须并进现有进程、流式处理、不常驻新进程、不整包读入内存。
- 无 HTTPS：所有涉及凭据的链路必须走 05 文档的加固方案，**不得新增任何明文传密码的入口**。
- 卡片是用户内容：必须有下架通道与举报入口，官方账号发布的卡免审但带标识。
- 一期不做：评论/点赞/关注、卡片版本迭代、付费、zip 上传、自定义知识库、多语言广场。
