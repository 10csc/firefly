```
A. 设置页与首页整改（图1+图2）        ← 纯前端+配置，风险最低，先落地
```

A → B →（C 与 D 结构先行）→ E 收尾。每阶段：全量测试 + 四门禁 + 沙箱实测 + 真机截图验收。

## 全程铁律

- 不 bump 版本号、不 push；每阶段本地 commit 一笔。
- 老用户数据零搬迁破坏：包结构新增项全部"缺省回落"，读取链不变。
- 删功能（首页卡片 / AI 搭建向导）= 删前端入口 + 摘除路由注册，后端模块文件归档到 `_trash/` 不硬删（保留回滚能力）。
- 所有新写文件路径必须过白名单校验（防穿越），写入即清相关缓存。

## 复审记录（2026-09-15，规划者对抗性自审后修订）
