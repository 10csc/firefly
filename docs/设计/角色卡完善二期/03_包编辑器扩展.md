## 二、后端端点（全部白名单 + 防穿越）

| 端点 | 方法 | 功能 |
|---|---|---|
| `/pack-knowledge` GET | ?mode= | 列出包知识库文件树（relative 路径 + 大小 + 是否用户副本） |
| `/pack-knowledge/file` GET | ?mode=&path= | 读单文件（path 白名单：包 knowledge/ 内 .md） |
| `/pack-knowledge/update` POST | {mode,path,content} | 写用户副本 `{pack}/character/knowledge/{path}` + `clear_knowledge_cache(mode)`（R-06 失效口终于落地） |
| `/pack-knowledge/delete` POST | {mode,path} | 删用户副本（回落 bundled）；自建包则删本体 |
| `/pack-knowledge/create` POST | {mode,path,title} | 新建知识文件（仅限五个子域目录 + .md + 合法文件名） |
| `/pack-memory` GET | ?mode= | 读出厂记忆（用户副本优先 → bundled） |
| `/pack-memory/update` POST | {mode,content} | 写出厂记忆用户副本 |

**共用校验**：`_safe_pack_path(mode, path)` —— 拒绝 `..`/绝对路径/非 .md/非白名单子目录；
写入走 `storage.atomic_write_text`；全部端点写后刷新三态标记（mark_slot 扩展支持 knowledge/memory 槽位）。
