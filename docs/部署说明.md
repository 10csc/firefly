# 服务器版部署说明（server/）

> 目标：把流萤部署到云服务器，鸿蒙 / iOS / PC 用户用浏览器打开 `http://<公网IP>:8765` 即可使用。
> **架构**：后端完全运行在服务器（复用本地版全部流水线逻辑）；**用户自己的 API Key 存在用户浏览器里**（localStorage），服务器只处理逻辑、用用户的 Key 调 DeepSeek API，**不落盘不存储 Key**；对话数据按匿名 UUID 隔离（`user_data/{uuid}/`）。
> 本地版（PC / 安卓 App）不受任何影响，代码在 `app/` 原样。

## 一、与本地版的区别

| 项 | 本地版（app/） | 服务器版（server/） |
|----|---------------|---------------------|
| 运行位置 | 用户设备（PC Python / 安卓 Chaquopy） | 云服务器 |
| API Key | 存本地 config.json | **存用户浏览器**（localStorage），每请求带 `X-API-Key` 头，服务器不落盘 |
| 用户数据 | 单用户 `user_data/` | 多用户 `user_data/{uuid}/` 按匿名 UUID 隔离 |
| 适用 | PC、安卓 App | 鸿蒙 / iOS / 任何浏览器 |
| 主动消息 | 全部支持 | 前台主动式/概率式正常；后台隐藏式不适用（无本地 Python） |
| 检查更新 | GitHub/Gitee 双源 | 服务器 `version.json`（管理员维护） |

## 二、部署步骤

```bash
# 1. 阿里云控制台：安全组放行 TCP 8765（默认只开 22，必做）

# 2. SSH 登录
ssh root@<公网IP>

# 3. 放行端口 + 装环境（Ubuntu 24.04 自带 Python 3.12）
apt update && apt install -y python3-venv
ufw allow 8765/tcp

# 4. 传代码（本地执行；server/ app/ modules/ knowledge/ database/ 都要）
scp -r server app knowledge database root@<公网IP>:/opt/firefly/

# 5. 建虚拟环境装依赖
cd /opt/firefly
python3 -m venv venv
venv/bin/pip install requests

# 6. 启动（后台守护）
nohup venv/bin/python server/server_app.py > /var/log/firefly.log 2>&1 &

# 7. 验证：浏览器打开 http://<公网IP>:8765 → 设置面板填入自己的 DeepSeek API Key → 开始对话
```

## 三、管理员维护

### version.json（检查更新）
服务器版前端"检查更新"读 `server/version.json`（与 server_app.py 同目录）。发版后更新：

```json
{"tag": "0.7.1", "exe": "http://<公网IP>:8765/firefly-setup.exe", "apk": "http://<公网IP>:8765/firefly.apk"}
```

### 全局设置（模型档位/主动性）
用户设置面板里除 Key 与接口地址外的配置（模型、思考等级、主动性参数）提交到服务器全局配置（`user_data/config.json`），所有用户共享——由你（服务器管理员）设定一次即可。

### 用户数据
- 每用户目录 `user_data/{uuid}/story/` 下（对话/记忆/手账/流水线）
- 用户换浏览器/清缓存会生成新 UUID → 旧对话不再关联（数据仍在服务器，可手动清理）
- 建议定期备份 `user_data/`（云备份权益已开通可覆盖）

## 四、安全说明

- **Key 不落盘**：服务器不存储任何用户 Key；请求头的 Key 仅用于本次调用（内存中）
- **UUID 隔离**：不知道他人 UUID 就读不到他人数据（UUID 只在用户自己的浏览器）
- **/shutdown 限本机**：公网请求 403，无法远程关闭服务器
- **路径穿越防护**：X-User-Id 白名单校验（字母数字 `-` `_`，≤64），杜绝目录穿越
- 已知边界：DNS rebinding 类攻击者只能在自己 UUID 下自娱自乐（读不到他人数据、Key 跨域不可读），危害有限

## 五、常见问题

- **提示"尚未设置 API Key"**：设置面板填入自己的 DeepSeek Key（只存本机浏览器）
- **别人能用我的 Key 吗**：不能——Key 只在你浏览器 localStorage，服务器不留存
- **换设备对话还在吗**：不在（UUID 是浏览器生成的）——当前为匿名模式，多设备同步是后续计划
- **带宽 3Mbps**：文本聊天富余，页面首次加载慢几秒属正常

## 六、本地版构建与发行（供发版时参考）

- **PC**：`python -m PyInstaller firefly.spec --noconfirm` → 清空 `dist/firefly/user_data`（`Remove-Item -Recurse -Force dist/firefly/user_data`）→ `ISCC.exe package\firefly.iss` → `package/firefly-setup.exe`
- **Android**：`JAVA_HOME=D:\Java\jdk-21` + `ANDROID_HOME=F:\CodeFile\firefly\android\sdk` + `gradlew.bat assembleRelease`（syncBackend 自动同步）→ 复制 `app-release.apk` → `android/firefly.apk`
- **版本**：5 处同步（app_config.APP_VERSION / app.js CURRENT_VERSION / gradle versionName / gradle versionCode / iss AppVersion）→ `python tools/check_version.py`
- **发行**：GitHub + Gitee release 双平台资产（exe + apk）；服务器版发版后同步更新 `server/version.json`
- **注意**：`user_data/` `dist/` `downloads/` `docs/搜索资料结果/` 不入库；Gitee token 在 `C:\Users\FANGL\.config\firefly\gitee_token.txt`

## 七、明确不做（YAGNI，防止未来过度设计）

- 不用 WebSocket/长连接（10s 轮询够用，观察远程延迟再定）
- 不做聊天记录加密存储（讨论必要性后再定）
- 不做账号注册系统（匿名 UUID 即可）
- 不改前端为独立 App（浏览器/H5 就是壳）

### 文件与部署

| 项 | 位置 |
|---|---|
| 脚本（仓库正式版） | `server/download_server.py`（零依赖，纯标准库） |
| 脚本（服务器运行版） | `/opt/firefly-downloads/download_server.py` |
| 下载文件目录 | `/opt/firefly-downloads/`（exe/apk/version.json） |
| systemd 服务 | `firefly-downloads.service`（User=www-data，开机自启，崩溃自动重启） |
| 端口 | 8787（ufw + 安全组已放行） |

### 更新安装包流程（覆盖同名文件即生效，无需重启）

```bash
scp -i ~/.ssh/id_rsa package/firefly-setup.exe root@<IP>:/opt/firefly-downloads/
scp -i ~/.ssh/id_rsa android/firefly.apk root@<IP>:/opt/firefly-downloads/
```

### 更新脚本流程

```bash
# 1. 本地改 server/download_server.py（唯一正式入口）
# 2. 上传 + 重启
scp -i ~/.ssh/id_rsa server/download_server.py root@<IP>:/opt/firefly-downloads/
ssh -i ~/.ssh/id_rsa root@<IP> 'systemctl restart firefly-downloads'
# 3. 发新版本时同步更新 version.json 的 tag 字段（exe/apk 链接不用动）
```

### 运维命令

```bash
systemctl status firefly-downloads   # 状态
journalctl -u firefly-downloads -f   # 访问日志/错误
systemctl restart firefly-downloads  # 重启
systemctl stop firefly-downloads     # 停止（公开通道关闭）
```

### 行为规则（代码内实现）

- 白名单：只提供 exe/apk/version.json 三个文件，下载路由为 **`/download/` 前缀**（如 `http://<IP>:8787/download/firefly.apk`），非白名单路径与路径穿越一律 404；根路径直链与旧 `?file=` 参数链接仍兼容
- 并发：同时最多 2 个大文件下载（>5MB），超出排队；同 IP 同时只允许 1 个（重复请求 429）；排队超 10 分钟 503
- 安全：socket 120s 超时 + 线程上限 64（防慢速 DoS）；www-data 低权限运行
- version.json 链接格式：`http://<IP>:8787/download/firefly-setup.exe`（公开，无鉴权）
