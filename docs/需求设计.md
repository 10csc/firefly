## 二、核心流程（V5）

```
用户输入
    │
    ▼
LLM 子代理检索（知识库整体注入 system 前缀 → 压缩知识摘要，无本地模型依赖）
    │
    ▼
分析器 Analyzer
  ─ intent / fact_check / summary
    │
    ▼
回复器 Polisher
  ─ 角色设定 + 分析摘要 + 历史 → 多条文本
    │
    ▼
组织器 Organizer
  ─ story：可选表情包；haruno：旁白演出
    │
    ▼
写历史（内存 ContextManager + user_data/{mode}/data/conversation.jsonl）
```

### 运行时数据

| 路径 | 内容 |
|------|------|
| `user_data/config.json` | API Key、模型档位 |
| `user_data/character/` | 可编辑角色设定（优先于 bundled） |
| `user_data/data/conversation.jsonl` | 会话消息 |
| `user_data/story/手账.md` | 手账 |
| `memory/` | 跨会话记忆 + RAG 索引 |
