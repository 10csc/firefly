公告 · 使用指南

Firefly 是 AI 角色扮演应用（非真人），请勿透露个人敏感信息。

一、开始使用

1. 首页右上角 ⚙ 设置 → 填入 DeepSeek API Key → 保存

2. 回到首页，点击角色卡片进入聊天

Key 在 platform.deepseek.com 申请，仅存本机，不上传。

二、模式

首页的每一张卡片是一个角色包（角色卡 + 你与该角色的聊天数据），各自的人设与数据相互独立；同一个角色可以有多个包（如剧情与剧本各一个）。

三、常用功能

自动修复（热更新）：小 bug 修好后由服务器推送补丁，App 空闲时自动装上，不必重装。⚙ 设置 →「数据」→「自动修复」可开关、查看当前修复版本、手动检查或回退。

公告：就是这一页。更新说明与临时提醒由服务端下发，有新内容时首页公告栏会亮小圆点；拉不到时仍显示这份内置指南。

主动消息：在「角色卡管理」→ 点角色卡 →「主动消息」里开关与调频率（按角色独立）。

让角色休息：☰ 菜单 →「让角色休息」，把这段对话整理进记忆与手账。

撤回 / 清除：☰ 菜单 →「撤回上一轮」或「清除历史」。

表情 / 图片：输入框右侧 😊 表情包、🖼 发图（图片压缩后上传，原图不出设备）。

设定文件：☰ 菜单 →「设定文件」，三样都是聊天产生的私有数据——用户记忆（压缩摘要）、历史对话存档（整理后的原文，可按月查看/编辑/「AI 压缩」）、手账；「清除历史」会一并清空它们。你手写的「用户设定」在「角色卡管理 → 人设与口吻」里，不受清除影响。

记忆怎么走：分析器与回复器读的是活跃窗口（自上次整理以来、常驻 30–100 轮的完整对话原文）；攒到 100 轮时在回复发出后自动把「最近 30 轮以外」的部分搬进历史对话存档（只进检索器），并在聊天页顶部提示。也可以随时点菜单里的「让角色休息」立刻整理。

外观：首页 ☀️/🌙 切换主题；⚙ 设置里可调界面大小。

返回：聊天页返回 → 首页；首页返回 → 双击退出。
