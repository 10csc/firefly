📢 公告 · 使用指南

一、基础配置（首次使用必看）

1. 在首页右上角点击 ⚙ 设置

2. 填入你的 DeepSeek API Key

3. 保存后即可开始与流萤对话

Key 可在 platform.deepseek.com 申请，仅保存在本机，不会上传。

二、关键功能

让流萤休息：对话积累后，在 ☰ 菜单点击「让流萤休息」——她会把这段时间聊过的内容整理进记忆与手账。醒来后，她会记得你们的约定、你的偏好和重要的事。

撤回上一轮：☰ 菜单「撤回上一轮」可删除最近一轮对话。

表情包：输入框右侧 😊 可打开表情包面板，选择表情发送。

设定文件：☰ 菜单「设定文件」可查看与编辑流萤的角色设定、短信样本。
