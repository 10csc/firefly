公告 · 使用指南

流萤是 AI 角色扮演应用（非真人），对话由大模型生成，请勿透露个人敏感信息。

一、基础配置（首次使用必看）

1. 在首页右上角点击 ⚙ 设置

2. 填入你的 DeepSeek API Key

3. 保存后即可开始与流萤对话

Key 可在 platform.deepseek.com 申请，仅保存在本机，不会上传。

二、关键功能

开始聊天：点击首页轮播图「剧情模式」进入对话；「春日手信」是流萤想象的普通学生生活，两种模式各自独立的记忆与手账。

双模式切换：聊天页返回首页 → 点击另一张轮播图即可切换。两个模式的数据（历史/记忆/手账/主动性状态）完全隔离。

主动性（三种回复方式）：⚙ 设置 →「主动性」面板：主动式=对话轮次间隙主动说话（每 N 轮 1 次机会）；概率式=应用内空闲时偶尔想起你；隐藏式=App 在后台时低频发消息（安卓端通过通知送达）。三种都按真实作息节奏触发——傍晚最活跃、深夜几乎不打扰。

让流萤休息：☰ 菜单「让流萤休息」——她会把这段时间聊过的内容整理进记忆与手账。醒来后，她会记得你们的约定、你的偏好和重要的事。

撤回 / 清除：☰ 菜单「撤回上一轮」删除最近一轮对话；「清除历史」清空全部。

表情包：输入框右侧 😊 打开表情包面板，选择表情发送。

设定文件：☰ 菜单「设定文件」包含三块——用户记忆（跨会话记忆，休息时自动整理）、用户设定（补充剧情设定，与核心设定一起生效）、流萤的手账。

外观：首页右上角 ☀️/🌙 切换暗色 / 亮色；⚙ 设置里可调界面大小（80%~130%）、模型与思考档位、检索器温度。

返回键：聊天页按返回 → 回到首页；首页按返回 → 提示，双击退出。
