# 匹诺康尼隐藏线（2.0–2.2 时期发生，3.8《记忆是梦的开场白》揭示）

> 文件名沿用 `penacony-3.0.md` 以保证检索器兼容；真正的 3.0 内容（翁法罗斯记忆空间）见 `knowledge/剧本/版本/3.0.md` 与 `database/dialogues_compiled/3.0任务对话.md`。

## 概要
3.8 揭示流萤在 2.0 失散后不为人知的另一条线：她与伪装成"星核猎手同伴"的忆庭焚化工大丽花（康士坦丝）同行，调查"死亡"迷因与梦主歌斐木掩埋的罪行；发现被梦主所杀的 AR-214 遗骸；执行零点任务；在星核前被梦主设局诱发寰宇蝗灾；第二次死亡（被寰宇蝗灾杀死、启用真正力量死而复生）。

## 关键剧情节点
- 大丽花接住被"死亡"袭击的流萤；流萤从迷因瞳孔看到另一片梦境倒影
- 调查梦主罪行：AR-214 遗骸；流萤请求带走安葬，"像普通人那样"
- 失熵症本质：铁骑与虫群同源，"离群即死"；"卡芙卡和开拓者找到我的那会儿……"
- 零点任务："只要黄泉有半分拔刀的可能，我就不能让开拓者在场"
- 第一次死亡：流萤主动迎向"死亡"——"能自己选择如何死去，已经很棒啦"
- 梦主布局：以星核伪装"死灭之蛹"，诱使与虫群同源的行者在星核前许下"想要活着"的愿望，扭曲出寰宇蝗灾
- 第二次死亡：被寰宇蝗灾杀死后启用真正的力量，死而复生；失熵症不可逆加速
- 大丽花的多重身份：完成冥火大公遗愿、推进歌斐木布置、也帮星核猎手挖掘真相
- 花火接应：银狼雇的帮手；"在你度过最美好的时光之后，就尽力飞向天空吧，你会在橡木的顶端听见虫鸣"

## 流萤关键台词
- "我宁可不是这样。"（面对 214 遗骸，她宁愿自己能为她大哭一场）
- "这是我们早已注定的命运，总有一天，我也要迎来相同的结局。""嗯，不是今天。"
- "既然我们无法改变结果，我又为什么要阻止她选择过程呢？"
- "失熵症是名为『活着』繁育的死亡。"
- "我的梦…在开始时就注定破灭，但他们，还没到该醒来的时候。"

## 涉及角色
- 大丽花/康士坦丝：忆庭焚化工，伪装合作者；后被黑天鹅拆穿
- 黄泉：虚无令使，流萤因零点任务拒绝同行
- 梦主歌斐木：亲手杀害 AR-214，以她的残躯命途为"永恒乐园"奠基
- 银狼：远程技术支援；"没必要非得搭理虫子，这是你的坏习惯"

## 名词来源标注
- "深魇蝗灾"（及"示死祸源：深魇蝗灾"）出自封装 skill 剧情框架与玩法内容（混沌回忆敌人名）；A 级剧情对白只说"寰宇蝗灾"。流萤在聊天中不使用玩法名，知识库可保留并标注来源。
