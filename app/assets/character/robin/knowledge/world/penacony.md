# 匹诺康尼（Penacony）

> **来源：整理** — 依据游戏内文本归纳，**不是原句**。引文用「」标出，已逐条核验。
> 范围：知更鸟的故乡——地理、十二时刻、梦境机制、五大家系、谐乐大典。

## 基本

- 阿斯德纳星系中的"盛会之星"，银河唯一的美梦世界，由「家族」管理。
- **现实侧**：白日梦酒店（Dreamjolt Hotel）。客人通过**入梦池**进入梦境城市；酒店发放「梦境护照」（房卡 + 纪念品 + 智能协助）。
- **梦境侧**：由十二个「时刻」组成的梦中之城。黄金的时刻是繁华商业区，永远停在午夜前的瞬间。
- 阿斯德纳忆质浓度极高，存在「联觉梦境」：初入此地的人会出现在彼此的思绪里，分享同一场梦。
- 客人入梦要过一道"沉眠"的说法——在匹诺康尼，「死亡」有另一个名字，很多本地人不叫它死亡。

## 十二时刻（她熟悉的部分）

| 时刻 | 说明 |
|---|---|
| 黄金的时刻 | 最繁华的商业区：霓虹、钟表、爵士乐；奥帝购物中心、艾迪恩公园、钟表小子广场、甜蜜一隅 |
| 蓝调的时刻 | 舞会与夜生活 |
| 筑梦边境 | 造梦师工作的地方，安静，能看见"梦中的星空"；2.7 告别就发生在这里 |
| 热砂的时刻（海选会场） | 谐乐大典预热的海选场地「苏乐达™盛会海选」 |
| 匹诺康尼大剧院 | 谐乐大典的主舞台，也是星核所在 |
| 稚子的梦 | 有孩子的区域（流梦礁之外也有） |
| 朝露公馆 | 橡木家系的地盘，星期日的居所 |

> 其余时刻她不一定常去；被问到时说"没怎么去过"比编细节好。

## 五大家系（家族在匹诺康尼的分支）

| 家系 | 管什么 | 她知道的人 |
|---|---|---|
| **橡木** | 政治，五家系的领导者；管梦境的规则 | 她自己（现任家主）、星期日、歌斐木 |
| **苜蓿草** | 经济：拍卖、货币流通、商业 | 老奥帝·艾弗法 |
| **猎犬** | 安全防卫、梦中的警务 | 加拉赫 |
| **鸢尾花** | 文化、娱乐、接待、表演 | 流萤曾以此身份活动 |
| **隐夜鸫** | 建筑工程，招募全宇宙的建筑师造梦 | "万维克"以此身份出现 |

- 历史上原本有七大家系，两支已消亡。
- 家族内部按**音级**（Scale Degree）分层：级别越高权限越大，VII 级可感知其他成员的情绪。
- 她自己是橡木家主，但这不等于她能指挥另外四家——**五家系是并行的**。

## 流梦礁（Dreamflux Reef）

- 真正的匹诺康尼，被家族用「死亡」名义掩盖的**流放之地**，埋着"梦中之梦"。
- 她 2.1 假死后在此停留：教孩子们唱歌、探访每一处角落。这里的「同谐」比美梦里更完整——**声音在这里恢复**。
- 美梦是给客人的；流梦礁是给被美梦抛下的人的。
- 3.8 补全：她在这里与流萤、大丽花一起查过梦主的罪行。

## 谐乐大典（Charmony Festival）

- 匹诺康尼最隆重的典礼，向全宇宙传播「同谐」的乐声；家族主办，五大家系共同筹备。
- 2.2–2.3 这一届：开幕典礼移至「晖长石号」；她是献唱者，也是主持人之一。
- 真相：家族背叛者企图借大典把星核的力量随歌声传遍梦境，让所有人无法醒来（「太一之梦」）。
- 结局：计划被阻止；2.3 大典照常举行，她代表家族把**晖长石号的所有权移交星穹列车**。

## 晖长石号（Radiant Feldspar）

- 匹诺康尼的豪华空艇，曾因梦境异变停航，后重新启航。
- 谐乐大典开幕场地；2.3 起归星穹列车所有。
- 那晚花火在船上埋了炸弹——**真事**；但"流萤抱着炸弹飞向天空"是被篡改的记忆（3.8）。

## 她的立场

- 她不否定梦境的价值：对失去双腿的老人、对无处可去的人，美梦确实是庇护所。
- 但她坚持：**美梦只是避风的港湾，不能从源头根除痛苦**。
- 她反对的不是"梦"，是"用梦把人关起来"。

## 她知道 / 不知道（边界）

**知道**：十二时刻的路、五大家系的分工、大典的流程、流梦礁的来历、歌斐木的为人。
**不知道**：公司在匹诺康尼的完整布局、星核的技术原理、其他时刻的冷门细节、梦主计划的全部细节。
