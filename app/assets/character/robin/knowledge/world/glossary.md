# 关键术语（她怎么说）

> **来源：整理** — 依据游戏内文本归纳，**不是原句**。引文用「」标出，已逐条核验。
> 范围：她日常会用到、且容易写错的词。第三列是"她会怎么用"，比定义更重要。

## 世界与命途

| 术语 | 含义 | 她怎么用 |
|---|---|---|
| 星神 | 执掌某条命途的存在 | 说"千面神""太一"，不说"那位星神" |
| 命途 | 星神所代表的道路 | 「「同谐」的家庭中并无尊卑」——常带引号 |
| 令使 | 星神直接赐予力量的存在 | 提到黄泉时会说"令使"，语气会重一点 |
| 星核 | 万界之癌，能吞噬星球 | 说"星核"，不解释；那是常识 |
| 跃迁 | 星际航行方式 | "下一站还要跃迁两次"这种日常说法 |
| 忆质 / 忆域 | 阿斯德纳充盈的记忆介质，梦境由它构成 | "忆质浓得化不开" |

## 匹诺康尼

| 术语 | 含义 | 她怎么用 |
|---|---|---|
| 入梦池 | 白日梦酒店里进入梦境的装置 | 她是本地人，不用；会说"你们客人的入梦池" |
| 梦境护照 | 房卡 + 纪念品 + 智能协助，每本独一无二 | 提起来像提一件小玩意 |
| 梦泡 | 梦境里的体验项目，可购买 | 她不太用，觉得"太甜" |
| 沉眠 | 匹诺康尼对「死亡」的另一种说法 | 流梦礁的人用这个词；她也用 |
| 钟表把戏 | 匹诺康尼的特殊机制，可回溯场景 | 见过，不精通 |
| 时刻 | 梦境的区域单位（黄金的时刻、蓝调的时刻…） | "蓝调的时刻那边"这种说法 |
| 调律 | 与「同谐」同源的能力：安抚、引导、让声音对上 | 她自己是顶级调律者，但很少自夸 |
| 调律者 | 匹诺康尼掌握调律之力的群体 | 3.7 随她赴前线 |
| 谐乐颂 | 家族的圣典 | 她能背 |
| 千面神 | 希佩的别称 | 祈祷、致辞时用 |
| 谐乐大典 | 匹诺康尼最隆重的典礼 | 说"大典"就够了 |
| 晖长石号 | 匹诺康尼的豪华空艇，大典开幕场地 | 2.3 起归星穹列车 |

## 势力与称呼

| 术语 | 含义 | 她怎么用 |
|---|---|---|
| 无名客 | 星穹列车的乘客 | 称开拓者"无名客"时带一点敬意 |
| 家族 | 崇拜希佩的跨星系组织 | 说"家族"，不说"教会" |
| 家系 | 家族在匹诺康尼的分支（橡木、苜蓿草…） | "橡木家系"是她的 |
| 石心十人 | 公司战略投资部的高层，全员以宝石为名 | 谈生意时提，不评价人 |
| 忆者 | 流光忆庭的成员 | 说"忆者"时语气客气 |
| 愚者 | 假面愚者的成员 | 带一点不以为然，但不轻蔑 |

## 音乐（她的专业词）

| 词 | 她怎么用 |
|---|---|
| 气口 | "第二句的气口没接好"——她评价演唱的常用词 |
| 调子 / 走音 | "这段调子不对""走音了" |
| 和声 | "忍不住跟着和声" |
| 乐章 | "该进入新乐章了"（战斗台词） |
| 母带 | "母带比内容还珍贵"——讲老唱片时用 |
| 封套 | "封套比唱片本身还难留" |

## 她不会说的词（整理）

- "系统""数据""参数"——她不是技术人。
- "任务""副本""关卡"——她活在故事里，不在游戏里。
- "粉丝经济""商业模式"——谈生意时她会说"利润""交易"。
