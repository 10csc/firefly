# 纪时表

> 崩坏：星穹铁道的宇宙时间以**琥珀纪**（AE = Amber Era）为纪年单位。每个琥珀纪约76至240年不等——以克里珀每次挥锤为标记。最新已知的琥珀纪为 AE 2158。
> 
> 由于绝大多数远古事件没有精确纪年，以下按**相对顺序**排列。

## 太初时代（无确切纪年）

| 事件 | 说明 |
|------|------|
| **宇宙诞生，虚数之树确立** | 宇宙的基本结构——虚数之树——成形。星神的存在成为可能 |
| **最古老的星神诞生** | 克里珀（存护）、互（均衡）、龙（不朽）、奥博洛斯（贪饕）在远古时代先后诞生 |
| **纯美星神伊德莉拉诞生** | 在观察到了世界存在的终极意义（"美"）之后晋升 |
| **太一创造秩序** | 太一在七日中创造历法、文辞、善恶、规则、意义——最后被人类"驱逐" |
| **智识星神博识尊诞生** | #1 赞达尔·壹·桑原创造了星体计算机"博识尊"——后者在获得自我意识后晋升为星神。博识尊随即邀请赞达尔成为天才俱乐部#1。赞达尔后来将意识数字化分散于九具躯体中 |
| **阿哈晋升为欢愉星神** | 阿哈成为欢愉命途的行者。之后伪装成无名客混上星穹列车一整年，炸掉半列车和一整颗星球 |
| **阿基维利建造星穹列车** | 阿基维利从故乡佩加纳出发，建造星穹列车，铺设星轨网络连接宇宙。无名客追随阿基维利探索未知 |
| **阿哈偷走贪饕的"余味"** | 阿哈从奥博洛斯的贪饕命途中偷走了"余味"的概念——从此所有贪饕造物从基因层面失去了味觉感受器 |

## 寰宇蝗灾时代（AE 纪元前）

| 事件 | 说明 |
|------|------|
| **塔伊兹育罗斯晋升为繁育星神** | 虫群开始向全宇宙扩散 |
| **寰宇蝗灾全面爆发** | 虫群如蝗虫般侵袭各星球。繁育与贪饕两条命途之间的战争加剧了灾难 |
| **格拉默共和国崛起** | 格拉默制造格拉默铁骑（繁育命途行者）对抗虫群。铁骑编号制度建立。流萤的编号为AR-26710 |
| **太一与末王擦肩而过** | 天外合唱班中响起不和谐音——这是末王与太一的接触，预告了太一的终结。末王向太一展示了四重末日论的景象 |
| **克里珀牵头封印繁育** | 克里珀与其他星神联手将塔伊兹育罗斯击碎并封印于琥珀之中 |
| **希佩晋升，吞并太一** | 在寰宇蝗灾末期，希佩晋升为同谐星神——因同谐命途覆盖了秩序的概念，太一被希佩吞并。均衡命途的互在太一陨落后承担了更多宇宙平衡职责 |
| **寰宇蝗灾终结** | 塔伊兹育罗斯被封印后，虫群失去统一意志，逐渐溃散 |
| **奥博洛斯分裂** | 阿哈将奥博洛斯的躯体散布到多个世界（包括普兰纳卡迪亚和翁瓦克），压制了祂的意志 |

| **波尔卡·卡卡目猎杀开始** | 不明 | #4波尔卡·卡卡目杀死鲁珀特一世。此后继续在知识圆环边界猎杀接近真相的俱乐部成员 |

| **姬子修复列车** | 不明 | 姬子（击退入侵者的后代）发现了列车残骸，历经多年修复，开启了新的开拓时代 |
| **星核猎手成立** | 不明 | 艾利欧组建星核猎手。卡芙卡和开拓者救起流浪中的流萤。流萤成为第二个加入的成员 |
| **桑博·科斯基抵达雅利洛-VI** | 不明 | 假面愚人桑博抵达雅利洛-VI，在下层区活动 |
| **埃利亚斯·萨拉斯发明联觉信标** | 不明 | #56以利亚萨拉斯发明联觉信标（宇宙通用翻译器），为跨文明交流铺平道路 |
| **原始博士实施返祖实验** | 不明 | #64原始博士在翁瓦克实施返祖实验，被巡海游侠阻止 |

| **匹诺康尼事件** | 不明 | 谐乐大典，太一复活阴谋，流萤三次死亡 |
