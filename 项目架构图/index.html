01 / TOPOLOGY

三端架构拓扑

同一份 app/ 业务核心，三种运行形态。Windows 与安卓把后端打在本地、只绑回环； 服务器版在 8787 网关之上复用全部路由，按用户隔离。悬停节点查看高亮。

调用 / 数据流 复用共享核心 app/ 回落 / 降级路径 公网只暴露 22(SSH) + 8787；8765 / 8766 仅回环

[win]桌面版要点

  • server.py 227 行：入口，多开检测 + 优雅关闭 + 只绑回环网卡
  • 浏览器打开 127.0.0.1:8765 即完整应用，无需安装依赖
  • PyInstaller one-folder 产物 → Inno Setup 静默升级安装包

[android]安卓双模式

  • Chaquopy 把 Python 3.12 解释器和 app/ 一起打进 APK
  • WebView 加载本机 8765；启动 12 秒探测失败自动切服务器模式
  • 服务器模式：file:// 打包资产 + 云端 API，断网可浏览界面

[server]服务器版要点

  • 8787 网关做下载站与全站反代，300 次/分/IP 限流
  • 8765 业务层用 contextvars 实现每用户数据隔离
  • 8766 管理后台仅回环，SSH 隧道 + X-Admin-Token 双因子进入

05 / SERVER

服务器版细节

阿里云 101.200.14.126 上的多用户形态：四层认证门槛、relay 代发、托管额度池、 攻击哨兵与每日备份。公网面被压到最小。

[auth]认证四门槛

  1. QQ 邮箱验证码：5 分钟有效、一次性使用
  2. QQ 群邀请：群成员资格校验，圈住同好用户
  3. install_id 一安装一号：设备指纹绑定，防小号批发
  4. IP 限流：登录接口独立限频，失败 5 次锁 15 分钟（计数落库 + 写路径自愈清理）

凭据与令牌

  • 密码 scrypt 哈希；token 30 天滚动续期
  • token 以 sha256 哈希落库（v2 迁移透明完成）；2026-09-13 顺序迁移至 v3（sessions/notices 索引）

[relay]relay 代发机制

  1. 浏览器 1s 轮询 /relay/pending 取待发请求
  2. 用户 Key 本地直连 DeepSeek 代发，Key 不出本机
  3. 结果回传 /relay/result；CORS 失败时降级 /relay/proxy 由服务器代发
  4. proxy 路径下 Key 内存即弃、不落盘

托管额度池 QuotaClient（C-2，09-13 已加固）

  • 账号授权门槛：仅 quota_api_proxy>0 或 admin 可入托管，否则静默降级 relay 并记日志
  • 个人日限额（quota_api_proxy）+ 全站日池 5000 次双闸门；运行时锁 mimo-v2.5
  • 托管 Key 只认 FIREFLY_PROXY_KEY（已移除主 Key 回落）；成功才记账，失败记 proxy_usage_failed

[admin]管理台与运维

  • 管理台：用户列表 / 封禁 / 额度调整 / 下载统计 / 最近请求
  • _harden/ 本机一键管理后台套件：SSH 隧道 + 令牌注入代理
  • attack_watch.sh 服务器端每分钟扫描访问日志
  • 本地 attack_sentinel.py：SSH 收诊断 → DeepSeek 分析 → 弹窗 + 安全日报；高危触发 .shrink 收缩注册
  • 每日 3:00 cron 备份，保留最近 7 份

[risk]遗留风险 · 诚实清单

明文 HTTP 全链路

HTTPS 等待域名决策；目前靠回环 + token 哈希缓解，公网段仍是明文。

apk 内嵌模型不可热更

安卓端后端随构建打进 APK，服务器热修对本地模式不生效，需等下次发版。

_SESSION_MAX = 30 全局帽

限流表自愈破绽

限流表超 5000 IP 时整体清零，极端情况下给攻击者一个重置窗口。

审计日志内存态

server/ 不入 git

只走 scp + 本地副本，无版本历史，回滚靠备份。
